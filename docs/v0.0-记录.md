# v0.0 记录

v0.0 是一块通过 USB 连接电脑的 ESP32 + 1602 屏幕，接入了 Claude Code、Codex 和 DeepSeek harness，用来显示工具、状态和项目名。

目前有几处不足：

- 工具只用 C、X、D 单字母表示，太粗糙，希望改成更完整的名称，或者工具自己的图标。
- 左边不该一直是拆成几块的机器人，希望每个工具有自己的吉祥物，例如 Claude 的小螃蟹。
- 状态区分不够明显：工作时左看右看，完成时微笑举手，仍不容易一眼分清。
- 缺少待机提示，例如 “ready to work” 或 “waiting for your input”。
- 屏幕只有收到会话上报才会变化；希望它跟随鼠标、键盘所在的前台焦点，让人机协作的感觉更直接。

下一步先在现有硬件上改软件。v0.1 围绕这五点改进：更完整的工具名、各工具的吉祥物、更清晰的状态、待机文字，以及跟随前台窗口的焦点显示。

连接和硬件形态暂时后置。现在的 USB 线比较笨重，以后可以考虑直接插在电脑上的小 Type-C 插件、HDMI，或者像蓝牙鼠标那样的小型无线 USB 接收器。无线之后，放在哪里、怎样不弄丢，也会成为需要考虑的问题。这些想法先记下，当前硬件有限，暂不展开。
