# 简报：管理面板里写清每颗键"按下会怎样"

## 现状
面板（`pc/panel.py` + `pc/ui/panel.js`）每颗键只显示一个名字，比如"批准""发'继续'""到最新"。选中一颗键后，详情里也只写"当前功能：名字"。按下以后具体会发生什么、什么情况下不做事，都没有写。用户要求每颗键都标出按下的效果。

## 要改
1. **效果文字由 `panel.py` 生成**：
   - 在 `_bindings` 的每个条目里，和 `label` 并列加一个 `effect` 字段，再加一个函数 `action_effect(action, layer, code)`。
   - 不要把文字写死在 JS 里。这样用户改键以后，效果会自动跟着变。
2. **文字要求**：
   - 大白话，每条一两句，写清"什么情况下不做事"。
   - **必须和代码实际行为一致**：逐条对照 `hub.py`、`hub_desktop.py`（包括 `DesktopEffects` 里按层切换的处理）的实际代码路径。
   - 下面草稿取自 `agentdeck/键位方案-v9.md`，可能过时。和代码对不上的，以代码为准，并在回复里指出文档哪里过时。
3. **界面上三处显示**：
   - 选中一颗键时，在"当前功能：X"下面加一行"按下会：……"。旋钮显示三行：顺时针 / 逆时针 / 按下。
   - 键位图下方加一块"这一层每颗键按下会怎样"清单：按排列出 20 颗键和 4 个旋钮（每个旋钮 3 个动作），跟着上方选的层变化；改过的键显示改后的效果。
   - 鼠标悬停在键上时，提示里也显示效果。
   - 键上原来的短名字不变。
4. **自定义的功能也要有效果文字**：
   - 自定义程序（`app exe:`）：说明切到哪个程序的窗口；
   - 提示模板：说明在什么条件下把哪句话发出去；
   - 空键：写"不做事"；
   - 不认识的动作：写一条兜底文字。
5. **加一个开发用预览** `pc/panel_preview.py`：
   - 用假数据把面板起在 127.0.0.1 上，打印一个能直接打开的地址（带登录码）。
   - 不连真的 hub，不读键盘，不写用户真实的 `~/.agentdeck`（用临时目录）。

## 效果草稿（以代码为准）
**固定键：**
- **批准 / 拒绝**：有批准请求时，在 Claude/Codex 自己的批准框里点"允许"或"拒绝"；没有请求时不做事。（查清现在走的是点按钮，还是回钩子。）
- **语音**：把会话窗口调到前面，按一下听写快捷键（现在是右 Alt，触发 Typeless）；再按一次结束。（查清会不会先把光标放进输入框。）
- **发送**：Agent 层里，输入框有字就点"发送"，空的不做事。查清其他层做什么。
- **打断**：Claude/Codex 里点"停止"，没在跑就不做事；其他应用里按 Esc；正在用旋钮 1 切窗口时，取消这次切换。
- **清空输入框、截图（截完把路径贴进输入框？）、复制、粘贴、上一个窗口**：按代码写。
- **浮窗 / 帮助**：点一下显示或隐藏浮窗；按住显示当前层的键位图，松开消失；按住时转旋钮可以挪浮窗。
- **第 5 排第 4 颗**：和旋钮 2 逆时针是同一个信号，写清楚。

**第 1 排：**
- 把对应应用调到前面；已经在前面时回到上一个窗口。
- Claude/Codex 键在两个都开着时互相切换。
- 没开时提示找不到，不会帮你启动。

**第 2 排（按层）：**
- **Agent**：发"继续" / 发"跑测试" / 发"总结进度" / 到最新。模板只在输入框为空、没在等批准时才发。agent 在提问时，这一排变成选项 1–4。
- **聊天**：下一个未读 / 找人（微信 Ctrl+F，飞书 Ctrl+K） / 填入"收到"但不发送 / 到最新。
- **浏览器**：后退 / 地址栏 / 关标签 / 刷新。
- **视频**：播放暂停 / 上一条 / 下一条 / 全屏。
- **默认**：后退 / Tab / 关闭 / 到底。

**旋钮：**
- **旋钮 1**：
  - 转动：在 Alt+Tab 里前后移动，第一格先到上一个窗口；
  - 按下：确认切换；没在切换时回到上一个窗口。
- **旋钮 2**：
  - 转动：在会话卡片里上下移动，不动窗口；
  - 按下：卡片开着时跳到选中的会话；没开时跳到下一个等你的会话。
- **旋钮 3**：
  - 转动：顺滑滚动当前那一栏，Claude 里默认是对话区；
  - 按下：换下一栏，各栏画框标名字。
- **旋钮 4（按层）**：
  - Agent：agent 提问时在选项间移动，否则在提示模板里选；按下回车，列表开着时是确认；
  - 聊天：上一个 / 下一个聊天；
  - 浏览器：切标签页；
  - 视频：快退 / 快进 5 秒；
  - 默认：上下方向键。

## 不要做
- 不改任何按键的实际行为，不改键位文件和版本号，不改固定键的锁定逻辑，不动动画。
- 不写 `~/.claude`、`~/.codex`、`%APPDATA%\Claude`；不往 0xFF00 接口或 COM4 发东西；不动正在运行的 AgentDeck，不重新打包（我来做）。

## 做完的标准
- **测试**：
  - 每颗键、每个旋钮动作、每一层都有非空的效果文字；
  - 自定义程序、模板、空键、不认识的动作都有效果文字；
  - 面板 state 接口返回 `effect`；
  - 改键后效果跟着变。
- `pc/test_*.py` 全部通过：逐个用 `D:\conda\miniconda3\python.exe -X utf8` 跑；`test_verify_real_session.py` 偶发失败时单独重跑确认。
- **回复里要有**：
  - 完整的"动作 → 效果文字 → 依据的代码位置"对照表；
  - 和键位文档对不上的地方；
  - 改动文件列表。
