Help

下载与安装帮助

软件未向浏览器和操作系统申请数字签名，因此下载或首次打开时会出现安全提示。以下为各平台的正常处理方式，完成后即可正常使用。

Edge / Chrome 提示「已阻止不安全文件」，下载被拦截
这个提示由浏览器的下载安全策略触发，与安装包内容无关。按下面的顺序操作，中间会看到两种不同界面，按你屏幕上的继续即可。
01 打开下载列表，找到被拦截的文件

按 Ctrl + J，或点浏览器右上角的下载图标。

02 把鼠标移到文件上，点右侧的「⋯」，选「保留」
! CXT-Hub-1.0.0.exe不安全的文件 ⋯
03 接下来按你看到的界面继续
弹出提示窗口
详细信息 → 仍然保留

部分浏览器把「详细信息」显示为「显示更多」。

按钮变成「删除 ↓」
删除 ⌄ → 仍然保留

点「删除」右边的向下箭头，在展开的菜单里选「仍然保留」。

运行时提示「Windows 已保护你的电脑」（SmartScreen）
  1. 点击提示窗口中的「更多信息」。
  2. 点击右下角出现的「仍要运行」。
  3. 若随后弹出用户账户控制（UAC），选择「是」继续安装。

这是系统对缺少数字签名的应用给出的常规提示，确认安装包来自官方分享链接即可继续。

杀毒软件报毒，或安装包被自动删除
  1. 将安装包所在目录或文件加入杀毒软件的信任 / 白名单，然后重新下载。
  2. 也可临时关闭实时防护完成安装，安装结束后立即恢复防护。
  3. 从压缩包解压后提示文件损坏时，请重新完整下载后再解压。
提示「无法打开，因为 Apple 无法检查其是否包含恶意软件」
  1. 打开「系统设置 → 隐私与安全性」。
  2. 在「安全性」区域找到被拦截的 CXT Hub，点击「仍要打开」。
  3. 输入 Mac 登录密码确认，随后再次打开应用。

macOS 13 及以上也可以直接右键点击应用图标 →「打开」→ 在弹窗中再次点击「打开」。

提示「应用已损坏，无法打开」

这是 macOS 给从网络下载、且没有开发者签名的应用加上的「隔离」标记，并不代表文件真的损坏。按下面的步骤清除标记即可，全程约 1 分钟。

  1. 打开「终端」：按 Command (⌘) + 空格 调出聚焦搜索，输入「终端」（或 Terminal）后回车；也可以从「访达 → 应用程序 → 实用工具」中打开「终端」。终端是一个用于输入命令的窗口，看到光标闪烁即可继续。
  2. 粘贴命令：点击下方「复制」按钮，然后在终端窗口中按 Command (⌘) + V 粘贴：
    sudo xattr -rd com.apple.quarantine "/Applications/CXT Hub.app"
  3. 按回车，输入开机密码：按下回车后，终端会显示 Password:。这里需要输入你登录 Mac 时使用的开机密码。输入时屏幕上不会出现任何字符，连圆点或星号都没有，这是 macOS 的正常保护机制，不是卡住或没输进去；正常输入后直接按回车即可。
  4. 等待执行结束：密码正确时，命令会很快执行完并回到可输入的命令行提示，通常不会有「成功」提示；若显示 Sorry, try again，说明密码输错，重新输入即可。
  5. 重新打开应用：回到「应用程序」文件夹双击 CXT Hub。

请确认 CXT Hub 已拖入「应用程序」文件夹，并来自官方分享链接。如果应用名称或位置不同，请把命令引号中的路径替换为实际路径；不要对来源不明的应用执行此命令。

提示「无法验证开发者」，且没有「仍要打开」按钮
  1. 不要双击，改为右键点击应用 →「打开」。
  2. 若仍无选项，进入「系统设置 → 隐私与安全性」，在页面底部点击「仍要打开」。
  3. 公司或学校统一管控的设备可能禁止运行未签名应用，需要联系设备管理员。
以上提示仅与代码签名有关，不影响键盘连接与配置功能。请始终从官方渠道获取安装包。
Install

安装与连接

  1. 下载对应安装包：根据系统与芯片选择上方版本，网盘分享页中下载完整文件。
  2. 运行安装程序：Windows 按向导完成安装；macOS 打开 DMG 后将 CXT Hub 拖入「应用程序」。
  3. 连接键盘：打开 CXT Hub，用 USB 线连接键盘，软件自动识别后即可开始配置。
首次启动会引导你选择语言、主题与键盘外观；各功能首次使用时均有内置引导。
