# AgentDeck v0 晨报（2026-11-17）

## 结论
宏键盘 + 状态屏联动的软件已完成，离线测试 8 组脚本全过；真机冒烟（10 秒，主键盘放行、无误吞、正常退出）通过。**唯一没验证的：用宏键盘真按一遍。**

## 怎么用（一条命令）
```
D:\conda\miniconda3\python.exe pc/deck.py run -v
```
在 `D:\desk\hardware\h1` 下运行。窗口开着就生效，Ctrl+C 退出。运行期间宏键盘的出厂 Photoshop 键被吞掉、改做 AgentDeck 动作，主键盘不受影响。

| 宏键盘出厂键 | 动作 |
|---|---|
| E / B / Ctrl+Z / 空格 | 切到第 1–4 个会话（屏幕显示 + 窗口拉前台） |
| G | ✓ 批准（仅前台会话在等你时发 Enter） |
| Ctrl+F | ✗ 拒绝（同上，发 Esc） |
| H | 跳到下一个等你的会话 |
| L | 屏幕恢复自动轮换 |
| 旋钮 `]` / `[` | 会话轮换 |
| 其它键 | 吞掉，不做事 |

映射在 `pc/deck_map.json`，改完重启即可。

## 今早请你确认
1. 运行上面命令，按 E/B 看屏幕和窗口是否切换。
2. 让一个 Claude 会话停在权限确认，按 G 看是否批准。
3. 按宏键盘其它键，确认没往前台打字；主键盘打字正常。
4. 旋钮拧动是否轮换会话。
