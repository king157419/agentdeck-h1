# 让宏键盘不再打字：装 WinUSB 驱动

现在 AgentDeck 用 Raw Input 读宏键盘，按键会同时在当前窗口打出字母（E、B、G……）。
把键盘接口 0 的驱动换成 WinUSB 后，AgentDeck 自己改成 USB 直读，按键就不再打字。

1. 打开 https://zadig.akeo.ie ，下载 Zadig 并运行（会要管理员权限）。
2. 菜单 Options → 勾选 List All Devices。
3. 在下拉框里选 USB ID 显示 4132 2107 00 的那一项（宏键盘的接口 0）。
4. 右边驱动选 WinUSB，点 Replace Driver，等它提示完成。
5. 不用重启 AgentDeck：几秒后浮窗上的黄色提示消失，就是已经改成 USB 直读。

注意
- 只换 4132 2107 00 这一项。不要选 01、02 等其他接口，也不要选你的主键盘或鼠标。
- 换完后这把宏键盘在其他程序里不再当键盘用，只有 AgentDeck 能读。
- 想换回来：设备管理器 → 找到这个设备 → 卸载设备（勾选删除驱动）→ 拔插一次。
