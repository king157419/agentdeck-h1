## 一、一句话结论（v2 修订）

**赛道已被大厂验证，我们以 Codex Micro 为唯一产品标杆，但每家对手都只解决了一半问题。** OpenAI 的 Codex Micro 证明了"有人愿意为多 agent 实体控制器付 $230"[1]，但它锁死 Codex、只有 RGB 色灯无屏幕、且实测机身并无内置麦克风 [41]；Logitech MX Keypad 把 9 键 LCD 开发者控制台压到 **$99.99** 并原生支持 Copilot / Claude Code / Codex [43]，但采用薄膜按键、无内置麦克风、也无高危操作物理防呆；VibeKeys 把多 agent 状态钩子做到 $99 以内（仅旗舰 Max 带单块小屏与内置麦克风）[6][42]，但无对齐会话键的分栏详情与直答锁；**国内同样不是空白**——优篮子 Ulanzi 的 AU05 Vibe Key（¥269～299）虽有腾讯 WorkBuddy 联名款，但底层走通用 Ulanzi Studio 支持各家 AI、只是没有显示屏 [28][35][44]，而其带屏款 D200 系列（¥298～598 / $59.99 起）更已在官方插件商店免费上架同名开源项目 `puritysb/AgentDeck` [23][38][45]。**"跨所有本地/云端/国产 agent 的 Codex Micro + 3.2–3.5 寸 6 等分状态屏配真机械轴 + 板载麦克风 + 高危操作物理二次确认"并卡在 ¥499 / $99 的产品，目前没有。**

## 二、竞争格局图（v2 修订）

**结论：硬件分三层，软件分三类；真正的威胁来自"$99.99 级通用带屏硬件 + 免费插件"与"官方 Auto Mode + 云端异步 agent"，而不是另一个硬件初创公司。**

### 硬件（v2 修订）

| 类别 | 代表产品 | 价格带 | 特点 |
|---|---|---|---|
| 平台绑定型 | Codex Micro（OpenAI × Work Louder）[1]、claude-desktop-buddy（Anthropic 官方开源）[14] | 开发板约 $20～30【待核实】～$230 | 深度集成自家生态（Codex 或 Claude Desktop），绝不支持竞争对手 |
| 通用控制器 / 多平台 AI 键盘 | Logitech MX Keypad（$99.99）[43]、Stream Deck（$99.99～179.99）[8][11]、Ulanzi D200 系列（¥298～598 / $59.99～99.99）[38]、Ulanzi AU05 Vibe Key（¥269～299）[28][44]、VibeKeys（$29～99）[6]、Keychron F4 HE（$34.99）[13] | $29～180 / ¥269～598 | 有成熟渠道或装机量；带屏款均为薄膜键且无内置麦，带麦款无分槽状态屏 |
| DIY / 开源 | agentsd [12]、Gavel [25]、claude-buddy-pico [24]、puritysb/AgentDeck（已上架 Mac App Store 与优篮子插件商店）[23][45] | 免费软件或约 $20～30 开发板 | 证明需求真实；`puritysb/AgentDeck` 已补齐 D200/Stream Deck 免费多 agent 看板 |

### 软件（v2 修订）

| 类别 | 代表产品 | 热度信号 | 和我们的关系 |
|---|---|---|---|
| 多 agent 编排器 | cmux（28.8k stars）[17]、Claude Squad（8.8k）[20]、Conductor（$22M A 轮）[21]、Vibe Kanban（28.7k，已宣布停止维护）[19] | 高 | 解决"看见和切换"，不解决"不看屏幕就能按"与物理防误批 |
| 官方状态视图与云端异步 agent | Claude Code `agent view` 与默认 Auto Mode [29][47]、Codex 桌面版"command center" [34]、Cursor Cloud Agents [47] | 官方主流 | 最大的软件替代力量：日常低风险审批被消灭，任务向云端迁移，迫使硬件转向"本地+云端统一槽位 + 高危动作物理确权" |
| 手机端 | Happy（24.7k stars）[18] | 高 | 解决"离开电脑"，我们解决"坐在电脑前"（并在个人 Pro 订阅中提供手机只读看板互补） |

**读法：** 软件侧淘汰很快（Crystal 2026-02 弃用并入 Nimbalyst [22]，Vibe Kanban 停更 [19]），说明纯软件编排器很难独立留住付费用户；与此同时，同名开源软件 `puritysb/AgentDeck` 免费上架优篮子商店 [45]，证伪了靠基础"状态显示 OEM 授权"赚钱的幻想。

## 三、前 7 名逐个拆解（含国内对手 Ulanzi 系列）（v2 修订）

### 1. Codex Micro（OpenAI × Work Louder）——核心对标标杆（v2 修订）

**结论：我们的直接对标标杆（形态、功能清单与叙事锚点），需求验证者；它的五大短板正好定义我们的产品升级点。**

| 项目 | 内容 |
|---|---|
| 价格 / 发售 | $230，2026-07-15 限量开卖，约 12 小时售罄，官方无大规模补货计划；eBay 转售最高挂 $1,850，7 月底约 $450 [1][41] |
| 形态 | 13 个低矮机械键 + 平面摇杆 + reasoning 档位旋钮；上排 6 个"Agent 键"用 RGB 颜色显示最多 6 个 Codex 线程状态（白=空闲、蓝=思考、绿=完成、琥珀=待输入、红=出错），单击选择、双击切到前台 [4][41] |
| 口碑 | Hacker News 讨论 306 分 / 253 评论，以怀疑为主 [3]："这只是个宏键盘，凭什么这么贵"；多人指出是 Work Louder 自家 Creator Micro 2（官网 $168 起 [41]）联名改款 [3][4] |
| 做错了什么 | ① **只服务 Codex**，不支持其他 AI 工具 [2]；② $230 偏贵，同类 DIY 约 $20～40 [2]；③ 闭源、不支持 Linux [3]；④ **PCMag 与 CNET 实测确认机身无内置麦克风**，"按住说话"键仅触发电脑端现有麦克风 [41]；⑤ **只有 RGB 灯光无屏幕**，看不到"当前线程在等哪条具体命令"，也无高危操作防呆 |
| 国内情况 | OpenAI 中文页显示 US$230、"缺货"，是否向大陆发货【待核实】[36]。国内媒体按汇率报道为"约 1500 元"，评价是"硬件没新东西、有信仰税"，但承认"同时跑 4～5 个 agent 才有价值" [33] |
| 对我们的意义 | **它是我们的产品原型标尺**：保留它验证成功的"6 颗矮轴会话键 + 批准/拒绝/说话键 + 旋钮"，在上方加一条 **3.2–3.5 寸 6 等分长条 IPS 屏**、补齐**板载麦克风**与**高危操作物理二次确认**，跨所有海内外/云端 agent，价格压到 **$99 / ¥499** |

### 2. VibeKeys——真正的价格对手（v2 修订）

**结论：已做到"多 agent + 接入 Claude Code 状态钩子 + 最高 $99 + 开源"，不能再低估其技术集成深度。**

| 项目 | 内容 |
|---|---|
| 价格 | Pro $29～39（有线）、Plus $49（蓝牙/Wi-Fi）、Max $99（带屏旗舰）、VibeBuddy $69（桌面状态伴侣），免运费 [6] |
| 形态与麦克风 | 6 键 + 导航旋钮；**更正：官网规格显示 Pro / Plus 均无内置麦克风**（仅靠语音键触发电脑端听写），**只有 $99 的 Max 内置麦克风并配有一块集中式 OLED/TFT 小屏**（3D 打印外壳）[6] |
| 支持与钩子 | 支持 Claude Code、Cursor、Codex、Gemini CLI、OpenCode、Copilot；固件与客户端开源（Rust）[6]。**更正：并非纯键位映射**——其开源组件 `second-state/vibekeys_app`（`vibekeys claude`）已接入 Claude Code 的 `SessionStart`、`PreToolUse`、`Notification`、`PermissionRequest` 等钩子向 Max 推送多会话状态，并通过 `second-state/vibetty`（MQTT）桥接远程终端 [42] |
| 做错了什么 | ① Max 仅有一块集中小屏，**没有与 6 颗会话键一一对齐的分栏命令摘要屏**；② 虽能用钩子读状态，但批准/拒绝仍靠键位映射而非携带 `shown_nonce` 的底层钩子直答，也没有高危不可逆命令二次确认；③ 3D 打印外壳质感偏极客 DIY；④ 无国产 agent 与云端异步槽位适配 |
| 对我们的意义 | **"多 agent + 接钩子看状态"本身已不是独家壁垒。** 同在 $99 价位，我们必须靠**量产注塑模具 + 6 等分长条屏对齐矮轴 + 防串窗钩子直答 + 高危物理二次确认 + 国产/云端生态**正面胜出 |

### 3. Logitech MX Keypad——$99.99 渠道最强的直接对手（v2 修订）

**结论：不再是信息黑盒——$99.99 官方定价直接封死了海外初创硬件的高价空间，既是头号价格锚点，也是潜在软件分发渠道。**

| 项目 | 内容 |
|---|---|
| 价格 / 发布 | **2026-09-08 正式独立发布**（沿用 MX Creative Console 键盘半区硬件，10 月跟进开发者宣传视频 [7]），**官方零售价 $99.99**（附赠 3 个月 GitHub Copilot Pro+）[43] |
| 形态与配置 | 3×3 共 **9 颗全彩独立 LCD 按键** + 2 颗翻页键（最多 15 页），USB-C 有线连接，依赖 Logi Options+（Win 10+ / macOS 13+）；**机身无内置麦克风、无旋钮/滚轮**，采用整屏导光硅胶薄膜按键结构 [43] |
| AI 与 SDK 支持 | 官方定位"开发者与 AI 编码控制台"，**原生宣传支持 GitHub Copilot、Claude Code、OpenAI Codex** 及 VS Code / IntelliJ；开放 **Logi Actions SDK**（支持 Node.js 与 C# 编写插件并上架 Logi Marketplace）[43] |
| 做错了什么 | ① **无板载麦克风**，无法直接按住对讲派活；② 硅胶薄膜按键缺乏机械轴盲操确认感；③ 交互逻辑仍是"随当前前台窗口自动切页的快捷键面板"，缺乏不切窗口直答后台指定会话 `PermissionRequest` 及高危命令物理防呆锁；④ 无国产 CLI 原生适配 |
| 对我们的意义 | ① **直接决定 v2 定价决策（D2）**：罗技 9 键 LCD 卖 $99.99，我们绝不能卖原计划的 $129，必须定在 **$99（早鸟 $79）**；② 靠 **"罗技没有的板载对讲麦克风 + 真机械轴 + 金属滚轮 + 高危操作物理二次确认"** 打错位体验；③ 可评估通过 Actions SDK 让免费控制层覆盖 MX Keypad 存量用户 |

### 4. Elgato Stream Deck + 插件——装机量最大的替代品

**结论：用户已有的 Stream Deck 加 $2～4 插件，就能拼出 70% 的 AgentDeck。**

| 项目 | 内容 |
|---|---|
| 价格 | MK.2（15 个 LCD 键）$149.99，Neo $99.99，Stream Deck +（带旋钮）$179.99 [11] |
| 官方动作 | Elgato 发布"用 Stream Deck 控制 Claude"页面：57 个斜杠命令的快捷配置、4 个旋钮控制权限模式等 [8]；把"AI Controller"当成新品类在推，并在营销里直接点名 Codex Micro"价格偏高" [10][27] |
| 插件生态 | Claude Code Approver $3.99、Claude Deck Windows $1.99、Claude Code Usage 等付费插件 [9]；开源 agentsd 已能显示会话状态、批准/拒绝、切换会话、中断，但仅 macOS、仅 Claude Code [12] |
| 规模 | Corsair 不单独披露 Stream Deck 销量；Elgato Marketplace 活跃用户超过 200 万 [26] |
| 做错了什么 | ① 没有麦克风；② 一家 agent 一个插件，用户要自己拼；③ 需要配 hooks，非开箱即用；④ 依赖 Elgato 软件 |
| 对我们的意义 | **我们的软件也应该能驱动 Stream Deck**——把它从替代品变成获客渠道 |

### 5. Keychron F4 HE 8K Vibe Coding Keypad——低端价格屠夫（v2 修订）

| 项目 | 内容 |
|---|---|
| 价格 / 形态 | $34.99，4 个磁轴可编程键，每键 RGB，带 Codex 与 Claude 预设，无麦克风、无屏幕 [13] |
| 做错了什么 | 只有 4 键，没有状态反馈，本质是"把 Enter/Esc 做大" |
| 对我们的意义 | 把海外"无屏 AI 快捷键"心理底价压到 $35（国内被优篮子 AU05 压到 ¥269）。**v2 据此坚决砍掉原计划 $59 / ¥299 的无屏 Lite 款（D2）**——低端引流靠免费软件直接兼容用户手头的普通宏键盘，不自己开模打必输的价格战 |

### 6. claude-desktop-buddy（Anthropic 官方开源）——官方信号（v2 修订）

| 项目 | 内容 |
|---|---|
| 是什么 | Anthropic 官方开源的 ESP32（如 M5StickC Plus）低功耗蓝牙（BLE）桌面伴侣参考实现，小屏显示状态动画与权限提示，物理 A/B 键批准或拒绝 [14] |
| 热度 | GitHub 约 2.7k stars、473 forks [14]；乐鑫（Espressif）发了新闻稿，社区出现至少 5 个移植版本 [15] |
| 覆盖范围更正 | **更正：并非完全不含 Claude Code**——它通过 Claude Desktop 桥接 BLE，**已支持 Claude Desktop 内的 Claude Code 与 Claude Cowork 权限请求与状态同步**；但仍不支持脱离 Claude Desktop 的独立终端 CLI，更不支持任何非 Anthropic 工具，且仅 2 个键、无语音输入 [14] |
| 对我们的意义 | 机会：公开 BLE 协议可作为我们对接 Claude Desktop 会话的补充官方通道。风险：印证巨头硬件方案永远只服务自家闭环，进一步凸显跨生态中立控制层的存在必要 |

### 7. Ulanzi 优篮子 AU05 Vibe Key 与 D200 系列——国内最近的对手（v2 修订）

**结论：优篮子同时卡住了国内"¥269 带麦无屏"和"¥298+ 带屏无麦 + 免费同名插件"两个身位；我们不能靠"它绑死腾讯"或"收它 OEM 费"立项，必须靠单品体验完整度突围。**

| 项目 | 内容 |
|---|---|
| **AU05 Vibe Key（SKU I018）** | 国内 ¥269～299（InfoQ 评测）[28]，台湾店 NT$1,549 [37]，海外官店约 $60～70 [44]；6 颗热插拔矮轴键 + 1 旋钮 + 全向驻极体麦克风，CNC 铝壳，300mAh 无线接收器连接，**无显示屏**（仅 3 种模式灯效）[28][32][35] |
| **生态更正（非绑定腾讯）** | **重大更正：并非锁死腾讯 WorkBuddy 生态！** WorkBuddy 只是国内联名宣发入口；海内外在售标准版底层均走通用 **Ulanzi Studio（V3.2.0+）**，支持自由宏映射、应用自动切换及 Agent 状态灯同步，官方明确宣传支持 **Claude Code、Codex、ChatGPT、千问、豆包** [35][44] |
| **D200 系列 + 同名免费插件** | 优篮子成熟带屏控制台 **D200 / D200H / D200X**（13～14 键整屏导光薄膜 LCD，海外 $59.99～99.99，国内电商日常 ¥298～598、大促补贴到手约 ¥260～290，**无内置麦克风**）[38]。同名 MIT 开源项目 **`puritysb/AgentDeck`** 不仅已上架 **Mac App Store** 并提供 `npx @agentdeck/setup`，还已作为**免费插件上架优篮子官方 `Ulanzi Studio Marketplace`（`ugc.ulanzistudio.com`）**，直接在 D200 上监控并操控 Claude Code、Codex、OpenCode、Kiro 等 [23][45] |
| 优篮子两款各自缺什么 | **AU05 Vibe Key**：完全无屏幕，多开时看不到"哪路会话在等什么命令"，审批靠模拟快捷键易串窗，无高危防呆；**D200 + 免费插件**：硅胶薄膜键无机械盲操手感、无内置对讲麦克风、无滚轮（基础版）、无硬件级高危命令二次确认 |
| 对我们的意义 | ① **彻底删除"向优篮子收 OEM 授权费"假设（D4）**，并在路演前改名避开 `AgentDeck` 撞名（D5）；② 免费软件主动支持用户手头的 D200 引流（D2）；③ 自有单款硬件定 **¥499（早鸟 ¥399）**，把 AU05 的"矮轴+内置麦+旋钮"与 D200 的"多槽状态屏"合二为一，再叠加底层钩子直答与高危物理二次确认 |

## 五、CtrlVibe 众筹失利的教训（v2 修订）

**结论：CtrlVibe 在 Kickstarter 主场仅获 59 人支持（约 1 万美元）实质失利——不能把原因推给平台流量，而必须正视"无屏像普通宏键盘、无深度协议演示、缺乏众筹前蓄水"三个真问题。**

| 事实 | 数据 |
|---|---|
| 产品 | "AI 工作流控制台"：拨轮切换 AI 工具、拨杆管权限、9 个机械键、语音提示，面向程序员与创作者 [16][46] |
| 结果 | 筹到 HK$80,514（约 1.03 万美元【估算】，按 7.8 港币兑 1 美元），仅 **59 位支持者**；因设定目标极低（HK$10,000）账面达成 805% 名义成功，但远不足以支撑硬件商业化量产 [16][46] |
| 时间 / 平台更正 | 2025-07-30 至 09-13，**众筹主平台为 Kickstarter** [46]；**PledgeBox 仅是众筹结案后收集地址的第三方履约管理工具**（类似 BackerKit），并非众筹流量平台 [16] |
| 对照 | 同期 Prolo Ring（键盘用户的光标与宏控制）2,865 人、48.4 万美元 [30]；M5Stack StackChan（AI 桌面机器人）4,142 人、358 万美元 [31] |
| 国内对照 | 摩点唯一搜到的键盘类成功项目 AuraFlow Tap 筹 ¥26.1 万、557 人，但偏娱乐；同期大量"AI + 概念"硬件未达目标 [39]；一篇对 44 个众筹项目的观察结论是"AI 两个字不卖钱，说清具体玩法才卖得动" [40] |

更正后的失利归因（供团队引以为戒）：

1. **时机太早。** 2025 年中只有 30.9% 的开发者用 agent [5]，Codex Micro 一年后才引爆品类关注；当时"一人并行管 5 个 agent"尚未成为高频痛点。
2. **Kickstarter 主场转化极低，暴露冷启动无私域蓄水。** 在全球最大硬件众筹平台仅拿到 59 单，说明缺乏前期软件活跃用户池与 $1 订金漏斗验证，硬上众筹必然冷场。
3. **无状态屏，外观与 $35 宏键盘无代差。** 9 颗无屏机械键无法让人一眼看懂"为什么不直接买个普通小键盘改键"——这与 Codex Micro 在 HN 挨骂的点完全一致 [3]。
4. **缺乏防串窗直答与高危防呆的硬核实机演示**【待核实，未见其底层钩子技术说明】。

**我们的对策（对齐 D6/D7）：** ① 先发免费软件兼容用户手头现有外设（当前 Windows 已支持 F13–F24 热键 + 置顶 6 槽浮窗免驱接入，macOS 版与 Stream Deck / D200 按键屏原生插件在路演前 8 周内补齐），招募 30～50 名重度多开用户跑出真实 D14 留存率与日均物理按键次数，众筹前积累 2,000+ 周活；② 引入严格预热纪律，先跑落地页**付费早鸟订金预约（海外 $1 / 国内 ¥9.9，路演前验证 ≥ 300 人且 CAC ≤ ¥60，2027-07 累计 ≥ 1,500 人才开注塑模）**；③ 众筹首屏不用渲染图，直接放"焦点在记事本、后台 agent 弹窗、一键无感直批 + 高危 `git push --force` 物理二次确认拦截"的一镜到底实拍。

## 六、威胁评估（v2 修订）

**评估主线（对齐 §二点五及 D1–D5）：以 Codex Micro 为核心对标坐标。**
Codex Micro（$230）定义了"多 agent 物理控制台"的标杆交互，但留出了**"跨平台中立 + 分槽状态屏 + 内置麦克风 + 高危物理确权 + $99/¥499 甜点价"**的生态位。所有竞争威胁，本质上都是在争夺或消解这片"跨生态版 Codex Micro"的生存空间：

| 威胁来源 | 对"跨生态 Codex Micro"主线的冲击 | 可能性 | 影响 | 时间窗 | 我们的 v2 应对策略 |
|---|---|---|---|---|---|
| **Logitech MX Keypad（$99.99）+ Stream Deck + Ulanzi D200（含免费 `puritysb/AgentDeck`）截胡** | 用成熟的百美元内 LCD 薄膜键盘 + 免费插件拼出"能看多 agent 状态"的 70% 体验，直接封杀高价初创硬件 | **极高** | **极高** | **已发生** | ① **砍掉多 SKU，单款定 ¥499 / $99（早鸟 ¥399 / $79）** 卡死罗技 $99.99 心理线（D2）；② 免费软件主动兼容 Stream Deck / D200 把对手装机量变成漏斗；③ 靠对手全都没有的**"板载麦克风 + 真机械轴 + 6 等分长条屏 + 高危物理二次确认"**转化核心用户（D1/D3） |
