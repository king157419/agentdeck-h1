## 三、路演用的 90 秒 Demo（据 Gemini 审阅第五节，手不碰主键盘和鼠标）

1. **0–25 秒，找人**：3 号键变成琥珀色 ASK。按一下，被压在最底下的 Codex 终端跳到前台。
2. **25–60 秒，安全批准**：
   - 先故意把焦点放在一个空记事本上；
   - Claude 请求运行 `pytest`，按一下 ✓，记事本里一个字都没多，后台 Claude 继续执行；
   - 接着 `git push --force` 请求亮起红色，按一下 ✓ 不放行，屏幕提示"再按一次"；
   - `curl … | sh` 直接锁死，设备上不允许放行。
3. **60–90 秒，用嘴派活**：用滚轮选中 Qwen Code 或 CodeBuddy 会话，按住说话键说一句中英混杂的需求。说话过程中别的会话弹窗，松手后文字仍然只进入选中的那个会话。

现在的状态：第 2 段的核心逻辑（单击批准、高危要按两次、拒绝、离线回退）已经在 Hub v1 用真实进程验证过。L3 锁死已在 Hub v1.1 实现并用真实进程验证；语音守护目标窗口已在 v1.2 实现（离线测试通过，真实听写待测）；F13–F24 全局热键和置顶小浮窗已在 v1.3 实现，并用系统按键验证（F19 返回 allow、F20 返回 deny）。还没做的：真实 Claude Code / Codex 会话测试；高危闸门在真实 auto mode 会话里的测试（`PreToolUse` 闸门 v1.4 已实现，用真实进程和真实系统热键验证，真实 auto mode 会话待测）；设备随机数校验；Demo 用的长条屏样机（现有实体屏是 1602 字符屏，软件侧已有虚拟 v2 设备窗口 `pc/hub_virtual_device.py`）；国产 agent 实测。离线测试：中枢 264 项单元测试（`test_hub*.py`，含演示模式与虚拟设备）+ 回放自检 12/12。
