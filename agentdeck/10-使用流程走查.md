# AgentDeck 使用流程走查：一天里每一步能不能只用宏键盘

> 2026-11-22。按用户口述的一天流程，逐步对照现在的软件（键位方案 v9 + 当前代码），再对照市面上的产品。
> 依据：`agentdeck/键位方案-v9.md`、`pc/hub_desktop.py`、Claude Code 官方文档、`research/history/竞品交互拆解-2026-11-22.md`（Codex 调研）。

## 一、12 步逐个过

图例：✔ 现在就能做；△ 能做但有缺口；✘ 做不了。

| # | 这一步 | 现在用键盘怎么做 | 判定 | 缺口和补法 |
|---|---|---|---|---|
| 1 | 插键盘、开机 | 登录 10 秒后 AgentDeck 由计划任务自己启动；键盘 10 秒没连上会弹提醒；今天起被连带关掉后也会自己回来 | ✔ | 键盘挂在扩展坞后面时，冷启动偶尔认不出，要重插（硬件层，不是软件） |
| 2 | 打开 Claude / Codex | 第 1 排第 1 键切到 Claude；两个都开着时在两者之间互切 | △ | **软件没开时不会帮你打开**，只提示"没找到窗口"。补：找不到就直接启动。另外**新版 Codex 现在认不出**（它改名叫 ChatGPT.exe 了，见第四节第 2 条） |
| 3 | 选会话，光标落进输入框 | 旋钮 2 转动选会话，按下跳过去；卡片没开时按下 = 跳到下一个等你的会话 | △ | 跳过去以后**光标不一定在输入框里**。"发送"和模板键会先把光标放进输入框，"语音"键不会（只把窗口调到前面）。补：跳会话、按语音前都先把光标放进输入框（键位方案里原定的第 3 步，还没做） |
| 4 | 滚动看回复 | 旋钮 3 顺滑滚动对话区（昨天修好了滚到隐藏面板的问题）；第 2 排第 4 键直接到最新 | ✔ | 等你上手确认方向和速度 |
| 5 | 回复、布置任务 | 第 5 排第 3 键语音（触发 Typeless）→ 第 4 排第 3 键发送，或旋钮 4 按下回车 | △ | 同第 3 步：光标不在输入框时，说的话落不进去 |
| 6 | 切走：别的会话、微信、视频 | 旋钮 1 切窗口；第 1 排直达微信、飞书、浏览器；视频层有播放、上一条、下一条 | ✔ | — |
| 7 | 回来时知道谁在等我 | 屏幕右边的竖条，每个会话一个色点加一个字（批、问、完、错、跑、闲）；有批准或提问时自动展开卡片；Claude 自己也会在会话做完、你没在看时发系统通知 | ✔ | 全屏看视频时竖条会不会被盖住，没验过；宏键盘本身没有灯和屏，看不到状态 |
| 8 | 批准权限 | 第 5 排第 1、2 键批准、拒绝。但这只对 AgentDeck **拦下的**请求有效 | ✘（按你现在的设置） | **更正（11-22 查代码）**：你现在把"拦截批准"设成了"从不"，请求直接交给 Claude 自己的批准框，**批准键不会替你点"允许"**，只会跳到在等你回答的会话。两条路：① 把"拦截批准"改回"总是"或"自动"，批准键直接生效；② 新做：不拦截时，批准键去点 Claude 批准框里的"允许"（像现在点"停止""发送"那样）。另外 computer use 那种"申请控制某个应用"的弹框也没验过 |
| 9 | 卡住、撞上限：停下、召回上一条、重发 | 停：第 4 排第 1 键（在 Claude 里点"停止"）。撞上限：AgentDeck 已经能收到"出错了，原因是用量上限"这个信号，会话标成"错" | △ | **召回上一条，宏键盘上还没有对应的键**：Claude 桌面版输入框按 ↑ 就能回到上一条（你 11-22 实测过；我起初根据一份 GitHub 反馈帖写成"没有"，那是错的）。补：加"重发上一条"键，按下就是光标进输入框、再按 ↑，改几句再按发送。另外把"撞上限，几点恢复"直接写在卡片上（Claude 窗口里读得到"5 小时额度用了 12%，几点重置"） |
| 10 | 打断、插话 | 桌面版支持边干活边发：直接语音 + 发送，Claude 做完手上这一步就会读到；要立刻停就先按"打断" | ✔ | 模板键（发"继续"等）只在输入框为空、没在等批准时才发，插话要用语音 |
| 11 | 旁问（by the way） | 还没有专门的键 | ✘ | **桌面版自带旁问**：Ctrl+; 或在输入框打 `/btw`，能看到当前会话的全部上下文，问完关掉不影响主任务。补：加一个"旁问"键 = 光标进输入框 → Ctrl+; → 自动开语音。**不需要光标定位** |
| 12 | 引用回复里的某一段 | 做不了 | ✘ | 三条路，从便宜到贵：① 直接说"你刚才第二点……"，模型听得懂，多数时候够用；② 做"引用模式"：旋钮在回复里按段落移动高亮，按下把那段引用填进输入框，再语音；③ 精确到半句话的选择，交给鼠标 |

**小结**：12 步里，5 步现在就能做（1、4、6、7、10），4 步能做但有缺口（2、3、5、9），3 步做不了（8：按你现在"拦截批准：从不"的设置，批准键不生效；11；12）。缺口里最便宜、最该先补的是：光标自动进输入框、认出新版 Codex、旁问键、重发上一条。

## 二、你问的几个具体问题

### 桌面版输入框里按 ↑ 能召回上一条吗？
- 终端版可以：↑ 翻历史；Esc 停止；输入框为空时连按两次 Esc，打开"回退"菜单，选一条以前的话，可以改了重发。来源：官方文档 interactive-mode、checkpointing。
- 桌面版也可以，按 ↑ 就回到上一条（你 11-22 实测）。官方快捷键表里没写这一条；GitHub 上有一份反馈帖（anthropics/claude-code#70678）说"以前有，后来删了"，那份说法不对，或者已经过时了。
- 所以"重发上一条"不用 AgentDeck 自己记，直接替你把光标放进输入框、按 ↑ 就行。

### 打断和插话怎么做？
- 桌面版官方说明：点停止按钮立刻打断；也可以不停，直接打一句纠正发出去，Claude 做完手上这一步就会读到。键盘上"打断"键（点停止）和"语音 + 发送"都已经有了。
- 桌面版快捷键 Esc 也是停止，但要求光标在页面里；AgentDeck 现在直接点"停止"按钮，不受光标影响。

### 旁问（by the way / side chat）是不是要用鼠标？
不用。桌面版自带：Ctrl+; 打开旁问，或者在输入框打 `/btw`。它能读主对话到这一刻为止的全部内容，但不会把问答塞回主对话。所以只要一个键：光标进输入框、按 Ctrl+;、开语音。来源：官方文档 desktop 页"Ask a side question without derailing the session"。

### 用户用桌面版还是终端版？终端版强在哪？
- 没有公开的比例数据。Claude Code 是从终端起家的，重度用户很多在终端里跑，常见用法是 tmux 或者终端多标签，一个窗格一个 agent。市面上的多开管理工具里，Claude Squad、cmux 这些都是终端工具，说明这群人不少。
- 终端版的好处：
  1. **一切都有快捷键**：↑ 召回、Esc 停止、两次 Esc 回退、Shift+Tab 切模式。宏键盘只要往终端发按键就行，不用像桌面版那样去找按钮。
  2. **多个会话并排看**：tmux 切成几个格子，一眼看到全部进度。不过桌面版现在也能把会话拖成左右分屏。
  3. **能连远程服务器、能写脚本自动跑**。
- 桌面版的好处：看改动、内置浏览器、旁问、系统通知、手机远程接管，不需要会用终端。
- 结论：先做桌面版是对的（你自己就在用，界面里的按钮能读到）。以后支持终端版，按键这一层反而更容易；难点在 tmux 里分清哪个格子是哪个会话。

## 三、市面上的产品怎么做

Codex 查了 24 个产品或配置的公开文档，总表和 51 条来源见 `research/history/竞品交互拆解-2026-11-22.md`。下面 3 条关键事实我又打开原页核对过：Claude 桌面版旁问、Codex 桌面版快捷键表、Antigravity 引用。

### 定位：没有一家硬件想"替掉键鼠"
- **给键鼠加速（大多数）**：
  - 硬件：Codex Micro、罗技 MX Keypad、Stream Deck 及其插件（Elgato 官方 Claude 配置、agentsd、Claude Code Approver、VibeDeck）、优篮子 AU05 / D200、Keychron F4 HE、Anthropic 的 claude-desktop-buddy。
  - 软件：Codex 桌面版、Antigravity、Claude Squad、cmux。
  - 它们接管的是高频、不用精确定位的动作：批准、拒绝、切会话、语音、看状态。打字和精确选择默认还交给键鼠。
- **离开电脑也能管**：Happy、Claude 官方的 Remote Control、VibeKeys Max 的 Remote 模式。手机上能看、能批、能说，同样不做引用。
- **真正想替掉键鼠的，只有无障碍工具**：
  - Talon：靠语音和嘴发出的声音控制电脑。
  - Windows 语音访问：说"显示数字"，再说数字去点。
  - Homerow / Hunt-and-Peck：给每个能点的元素贴标签，打标签就点。
  - 它们靠标签、数字、网格解决"点哪里"，代价是要学一套命令。
- **回答你的问题**：对手的定位是"管理 agent 时，把最常用的几个动作搬到手边"，不是接管键鼠。

### 难的四步，谁做了

| 步骤 | 做了的 | 怎么做 | 硬件里有没有 |
|---|---|---|---|
| 9 停止 → 召回 → 重发 | Claude 桌面版、Codex 桌面版、Codex 终端版、Claude 终端版 | Esc 停；空输入框按 ↑ 回填上一条，改完自己按发送 | 没有一家做全：agentsd、VibeDeck 只做了"停"；Elgato 的 Claude 配置把"输入历史"放在一个旋钮上，只对终端有用 |
| 10 插话 / 排队 | Claude 桌面版、Codex 桌面版、Antigravity | Claude 桌面版：干活时直接发，做完当前一步就读；Codex 桌面版在设置里选"排到下一轮"还是"立即插话"；Antigravity 把排队的消息摆出来，可以立即发、改、删 | Codex Micro 的官方演示里能排队 |
| 11 旁问 | Claude 桌面版（Ctrl+; 或 /btw）、Claude 终端版（/btw）、Codex 桌面版（Ctrl+Alt+S）、Codex 终端版（/side） | 开一个能看到主对话的小窗问，主任务照跑 | 没有 |
| 12 引用回复 | Antigravity App；Codex 手机端 | Antigravity：选中回复里的字，点"引用"或按 Ctrl+L，那段变成一张小卡片进输入框，再写追问。Codex 手机端：选中后"在旁问里问" | 没有 |

### 值得直接学的三个做法
1. **Claude、Codex 两个桌面版都能按 ↑ 回填上一条。** 只回填、不自动发，留给你改的机会。我们的键直接借用它。
2. **Antigravity：引用卡片。** 选中的那段先变成卡片放进输入框，看得见、能删掉，再决定发到主对话还是旁问。
3. **Codex 桌面版："跳到下一个要你处理的会话"（Ctrl+Alt+A）和"最近 1–6 个会话"（Ctrl+Alt+1–6）。** 跟我们旋钮 2 按下"跳到下一个等你的会话"是同一个思路，说明方向对。

## 四、建议按这个顺序补（都还没做，等你点头）
1. **光标自动进输入框**：跳会话以后、按语音之前，先把光标放进输入框。最便宜，影响最大。
2. **认出新版 Codex**：本机的 Codex 桌面版（应用包 OpenAI.Codex 26.1117）现在的程序叫 ChatGPT.exe，窗口标题是"ChatGPT"，OpenAI 把 Codex 并进了新版 ChatGPT 桌面应用。AgentDeck 还按"进程名里有 codex"来认，所以现在第 1 排切不到 Codex，在 Codex 里也不会切到 Agent 层。代码里是 4 处判断，见 `pc/hub_layers.py:17`、`pc/hub_desktop.py:544/653/1008`。
3. **旁问键**：Agent 层第 2 排第 3 键改成"旁问"。Claude 里按 Ctrl+;，Codex 里按 Ctrl+Alt+S，按下后自动开语音。原来的"总结"挪进旋钮 4 的模板列表。
4. **重发上一条**：Agent 层第 2 排第 2 键改成"重发上一条"，原来的"跑测试"挪进模板列表。Claude 和 Codex 桌面版都自带 ↑，所以这个键只做两件事：把光标放进输入框，再按 ↑。不自动发，你补一句再按发送。
5. **软件没开就启动**：第 1 排第 1 键找不到窗口时，直接启动 Claude / ChatGPT。
6. **撞上限写清楚**：卡片上写"用量用完，几点恢复"，恢复后按"继续"就行。
7. **引用模式（最后做）**：先靠嘴说"你刚才第二点……"。真要做就学 Antigravity：旋钮 3 在最新回复里按段落移动高亮，按下把那段做成引用放进输入框，再说追问。
8. **先验证再说**：computer use 那种"允许控制某个应用"的弹框，批准键能不能点到。点不到，就让批准键把弹框调到眼前，由你亲手确认。

## 五、用户想自定义按键：现在怎么改，和别人比怎么样

### 现在怎么改（依据 `pc/panel.py`、`pc/ui/panel.js`）
1. 双击托盘里的 AgentDeck 图标（菜单里的"管理面板"），打开面板。
2. 在键位图上点要改的那颗键。第 2 排和旋钮 4 要先选是哪一层：Agent、聊天、浏览器、视频、默认。
3. 从下拉菜单选功能，马上生效，不用重启。每颗键都有"恢复默认"。改过的键以后升级也不会被覆盖。
4. 能改什么：
   - 第 1 排：4 个常用应用，或者任意一个 exe。
   - 第 2 排：提示模板、8 个快捷动作（复制、粘贴、发送、清空、打断、截图、上一个窗口、跳到下一个等你的会话），或者空着。
   - 旋钮 4：列表上下、回车，或者空着。
   - 批准、拒绝、语音这些固定键，以及旋钮 1–3，故意锁住不能改。
   - 模板的文字内容不能在面板里改，只能手改 `~/.agentdeck/hub_keys.json`。

### 别人怎么改

| 产品 | 怎么改 | 比我们强在哪 |
|---|---|---|
| Codex Micro | ChatGPT 桌面版的设备设置里，在布局图上点键，选功能和键帽 | 功能从 ChatGPT 的命令、技能里选，也能指定任意快捷键；改完提示你换上对应的实体键帽；有"恢复默认布局" |
| Stream Deck | Stream Deck 软件里拖动作到键上 | 能从商店一键导入别人做好的整套配置（Elgato 官方推荐了 Claude 提示模板配置）；按前台应用自动换配置 |
| 罗技 MX Keypad | Logi Options+ 软件，加插件商店 | 每颗键是 LCD，带图标 |
| 优篮子 AU05 / D200 | Ulanzi Studio | 自由宏映射，按应用自动切换 |
| VibeKeys | 命令行 `vibekeys keymap 键 绑定`（只在键盘模式下） | 能绑任意组合键或一段文字，偏程序员 |

来源：Codex Micro 官方说明（learn.chatgpt.com/docs/features/codex-micro）、Elgato 的 Claude 专页、VibeKeys 键位文档、罗技开发者插件说明；优篮子见 `02-竞品分析.md`。

### 我们缺什么（按值得做的顺序）
1. **不能录任意快捷键和文字**：只能从 8 个动作里挑。别人基本都能录一组组合键，或者填一段文字。
2. **模板内容不能在面板里写**：要改文件。
3. **不能给新应用加一层**：层固定只有 5 个，比如没法给 VS Code 单独配一套。
4. **没有导入、导出**：配置没法分享。
5. **键帽对不上**：CXT 的键帽印的是 Photoshop 快捷键，看不出哪颗是什么。可以做"面板一键打印键位贴纸"。

### 我们强在哪
- 改完马上生效，升级不覆盖。
- 第 2 排跟着前台应用自动换层。
- 同一个面板里还能看会话、批准、切批准模式；Stream Deck 和罗技的软件只管键位。
- Claude、Codex 都能管；Codex Micro 只管 Codex。
