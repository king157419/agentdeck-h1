## 一、我们到底卖什么（纠正之前的方向）

**AgentDeck 是一块"用按键控制电脑上所有 AI agent"的桌面控制器。** 核心是**控制**，屏幕和灯只是给控制提供上下文。

用户坐在电脑前，同时开着 3～10 个 agent（Claude Code、Codex、Cursor、Gemini/Antigravity、Trae、Qwen Code……），AgentDeck 让他不用找窗口、不用记快捷键、不用打字就能：

| 动作 | 按键 | 怎么实现（不靠模拟键盘） |
|---|---|---|
| 跳到某个 agent | 6 个会话键（上方 6 等分长条屏显示状态 + 键下 RGB 灯，D1） | 守护程序把对应终端/IDE 窗口切到前台 |
| 批准 / 拒绝 | ✓ / ✗ | 直接回答 agent 的 `PermissionRequest` 钩子（Claude Code、Codex 官方支持） |
| 打断 | Ctrl+✗ 或专用键 | 向对应会话发中断 |
| 说话下指令 | 按住麦克风键 | 本地/云端语音识别 → 文字发进**当前选中的那个会话** |
| 把屏幕给 agent 看 | 截图键 | 截图存文件 → 路径或图片发进当前会话 |
| 常用指令 | Ctrl + 会话键 | "继续""跑测试""提交"等可编辑模板 |
| 翻会话 / 调档 | 滚轮 | 在会话间滚动；按住 Ctrl 滚动 = 调 reasoning effort / 权限模式 |

## 二、竞争格局的诚实结论

1. **需求已被大厂验证，不需要再证明"有没有人要"。** OpenAI × Work Louder 的 Codex Micro（$230）12 小时卖光；Logitech 2026-09 独立发布 MX Keypad（$99.99，D9 更正）；Anthropic 官方开源 BLE 桌宠接口（2.7k stars）；Elgato 把"AI Controller"当成品类在推。
2. **但这是个快速变挤的赛道。** VibeKeys $39～99、Keychron $34.99、Stream Deck 插件 $2～4、几十个 DIY 项目；CtrlVibe 众筹只拿到约 1 万美元（59 人）。**单纯"做一个 AI 宏键盘"已经不值钱。**
3. **（已被 D9 取代）多家竞品已经跨平台**：Codex Micro 只服务 Codex、Claude Buddy 只服务 Claude Desktop，但罗技 MX Keypad 原生支持 Copilot / Claude Code / Codex，VibeKeys 支持多家并接钩子，开源 puritysb/AgentDeck 已免费上架优篮子商店。"多 agent 控制层"不是空白，我们的差异在组合：长条屏逐会话状态 + 钩子直答防串窗 + 高危物理二次确认 + 国产 agent 适配。
4. **审批次数正在被官方压低**（Claude auto mode 2026-08 起默认），所以"批准键"不能是主卖点。主卖点是**"谁在等我 + 一键过去 + 不打字就能指挥"**。
5. **国内不是空白（raw-china.md 更正）**：优篮子 Ulanzi × 腾讯 WorkBuddy 已推出 Vibe Key，¥269–299，6 键 + 旋钮 + 麦克风，但**没有逐会话状态屏**；它走通用 Ulanzi Studio，不只绑腾讯（D9 更正）。Codex Micro 没在国内正式销售。国产 CLI 大多有 PermissionRequest 类钩子：CodeBuddy 27 个事件、Qwen Code 23 个、Kimi Code 20 个（Kimi 的不能阻断），这让"中立适配层"更可行。国内定价锚点是 ¥299，主力款要靠"逐会话屏 + 跨 agent + 安全审批"撑起溢价。

## 二点五、对标产品（用户定，2026-11-17）

**对标 Codex Micro。** 形态、功能清单、做工和叙事都以 Codex Micro 为标杆：多个 agent 状态键、批准/拒绝、按住说话、旋钮。路演一句话就是"跨所有 agent 的 Codex Micro，而且更便宜、能用在国内"。VibeKeys、Ulanzi Vibe Key 只是价格参照，不是对标对象。

## 三、定位（一句话）

> （已被 D3 取代，现行一句话：**跨所有 agent 的 Codex Micro + 高危操作的物理二次确认**。）原句：AgentDeck：多 AI agent 的统一遥控器，让一个人像指挥一个团队一样指挥 10 个 AI。

## 四、差异化（按投资人最在乎的排序）

1. **跨平台（D9 修订）**：目标是同一块设备管 Claude Code、Codex、Cursor、Gemini/Antigravity 和国产 Trae / Qwen Code / Kimi / CodeBuddy。现状：只有 Claude Code / Codex 接入了中枢，其余按各家钩子能力（应答 / 拦截 / 只读状态）逐家列入路线图，Kimi 的权限请求不能阻断、无法直答。竞品并非都锁死一家（见 D9）。
2. **真控制，不是宏**：通过官方钩子直接回答审批、定位到具体会话，而不是往前台窗口里打字。不会批错窗口，失败自动退回终端原生提示。
3. **安全审批**：上方长条屏显示要执行的命令摘要（D1）；按风险分级，危险命令必须长按或双键确认。把"一键 yolo"的骂声变成卖点。
4. **国内首发 + 国产 agent 适配**：单款 ¥499（早鸟 ¥399），海外 $99（早鸟 $79）（D2）。不再把"深圳供应链成本"当差异点。
5. **软件先行、硬件变现**：控制层软件免费，也能驱动 Stream Deck/普通宏键盘，用来拉用户；自有硬件体验最好，作为主要收入。团队版（审批策略、审计日志）是第二收入。

## 五、护城河（要讲实话）

- **不是硬件**：硬件 6 个月就能被抄。
- **是适配层、高危物理确权和团队策略**（D3/D4 修订，不再讲数据飞轮）：
  1. 每家 agent 的钩子、状态识别、会话定位都不一样，而且每月在变（我们已经踩过：`idle_prompt` 误报、Codex 只有 `notify`、窗口标题识别）。持续维护多家适配是工程壁垒。
  2. （已被 D3 取代）跨厂商的高危操作物理确权（Hardware 2FA for Agents）+ 团队审计；不讲"审批数据越用越准"，那条打不过官方分类器。
  3. 用户的模板、工作流、团队策略沉淀在我们的软件里，换设备成本高。
  4. 国内渠道 + 国产 agent 厂商合作（做他们的官方硬件伙伴）。

## 七、最大的风险（路演必须主动讲）

1. Anthropic / OpenAI / Logitech 自己做 → 我们走中立和国内，大厂不会做"支持竞争对手"的设备。
2. agent 越来越自主，审批消失 → 主卖点是"指挥和跳转"，不是审批；agent 越多，指挥需求越大。
3. 名字冲突：GitHub 上已有两个 AgentDeck 项目 → 路演前定新名或加限定词（D5：中文"点将台"，英文候选 Baton / HelmPad / MuxKey；Conductor Key 已删除）。
4. 众筹先例失败（CtrlVibe）→ 先做软件拿真实用户和留存数据，再众筹。
