## 一、结论先行

1. **单台毛利率（成本按 1 万台档）：国内 28%，海外 29%**（这里的毛利已扣掉渠道费、物流、关税、退货和保修）。如果只扣到手成本、关税和保修（硬件行业常说的"产品毛利率"），国内是 38%，海外是 52%。扣掉获客成本后，每台贡献国内 ¥79、海外 ¥115。**1 千台档每台都亏，众筹批的国内早鸟 ¥399 低于成本**（见 4.3、4.4）。
2. **审阅要求的"≥42%"目前只有海外的产品毛利率达到。** 国内要达到 42%，含预留的 BOM 必须压到 ¥202 以下，现在估算是 ¥220（1 万台档），也就是还要降约 8%。这是第一条"按目标成本设计"的指标，要用 D7④ 的报价来验证（4.5）。
3. **基准情景不靠下一轮也能活下来（default alive）**：融 ¥500 万，**现金最低在 2029 年 10 月，还剩 ¥35.5 万**，之后不会再低于这个数。**月度经营利润从 2030 年 5 月起持续为正**，2030 全年经营现金流 +¥25.8 万，2030 年末现金 ¥113 万。
4. **三年（2027–2029）收入合计 ¥1,043 万**：2028 年 ¥346 万（6,500 台，其中众筹 1,500 台），2029 年 ¥697 万（1.2 万台，软件 ¥62 万，占 9%）。2030 年延伸到 ¥1,005 万（软件 ¥144 万，占 14%）。
5. **安全垫很薄，靠三条纪律撑住**：①3 个创始人拿低薪（每人每月全成本 ¥1.2 万）直到盈利，如果按市场薪资，现金最低会到 -¥130 万；②只有攒到 1,500 个 $1 订金才开模；③2029 年 6 月如果现金低于 ¥80 万（基准是 ¥89 万），就执行削减方案（6.3）。
6. **融资推荐方案 B**：¥500 万，投后 ¥2,500 万，分两期各 ¥250 万；第二期的触发条件是周活 ≥ 2,000，并且众筹锁定 ≥ ¥50 万（或 $1 订金 ≥ 1,500 人）。**方案 A（¥300 万一次到账）按同样的经营计划，2028 年 8 月现金就会转负**，只能再融一次钱，或者把零售规模砍掉一半（第七节）。
7. **基准里软件收入占比不高（2029 年 9%），这是故意保守。** 投资人押的是"跨 agent 控制层 + 高危操作物理确认"能不能长成企业产品（Team 版）。硬件是让我们活下来、拿到用户的手段，不是天花板。

## 二、产品与收入来源

### 2.1 唯一一款硬件（D1、D2）

| 部件 | 规格 | 作用 |
|---|---|---|
| 状态屏 | 上方一条 3.2–3.5 寸长条 IPS 屏，画面分成 6 等分，正对下方 6 个会话键 | 每格显示一个会话的名字、状态和待批命令摘要 |
| 会话键 | 6 个矮轴机械键，每键一颗 RGB 灯 | 跳到对应 agent；灯色表示"在跑 / 在等我 / 出错" |
| 大键 | ✓ / ✗ / 按住说话，三个大号机械键 | 批准、拒绝或打断、语音派任务 |
| 功能键 | Ctrl、截图 | Ctrl + 会话键 = 常用指令模板；截图发进当前会话 |
| 滚轮 | 右侧金属滚轮 | 翻会话；按住 Ctrl 滚动 = 调权限模式或 reasoning effort |
| 其他 | MEMS 麦克风、ESP32-S3、USB-C 有线，**v1 不做蓝牙** | 少一套无线认证，少一块电池 |

**为什么选这个结构**：机械轴底下不透光，"整块屏 + 透明键帽"只能配硅胶按键 [审阅 致命问题 1]；6 块独立小屏太贵（raw-tech 估算 6 块 0.85 寸屏 1 千台档约 $36 [tech §4]），USB 全速传输也吃紧。长条屏放在键的上方，同时解决了手感、成本和带宽三个问题。形态对标 Codex Micro（6 个带灯的 agent 键），在它的基础上多加一条屏。

**不在基准里、只算上行空间的：**
- **Pro 款硬件**（铝壳、蓝牙、电池）：18 个月后再看，要等单款卖到 1 万台/年、蓝牙认证预算（BQB 首次约 $8,000 [tech §4]）有着落以后。
- **通用 OEM / 适配层授权**（上行空间很小，基准和路演都不讲）：理论上可以授权给没有自研软件的键盘厂，但同类开源插件已经免费铺开。**不再假设优篮子会付钱**：同名开源项目 puritysb/AgentDeck 已经作为免费插件上架 Ulanzi Studio 插件商店，能驱动 D200 控制 Claude Code、Codex、Antigravity [审阅 #11]，优篮子没有理由再为"状态显示 + 跳转"付授权费。
- **模板市场**：装机量过 5 万台之前只当留存工具。Elgato 的插件市场能赚钱，是因为背后有 200 万以上活跃用户 [comp §2]。
- **国产 agent 厂商合作**（Kimi、智谱、Qwen、CodeBuddy、Trae）：买设备送 coding 套餐、联合推广。基准里不算现金，只把它当作降低获客成本的手段 [china §1]。

### 2.3 Pro 和 Team 凭什么能收到钱（回应 致命问题 4）

v1 的 Team 版只是一份放在 Git 里的签名策略文件，日志也发到公司自己的服务器，客户花一下午写个脚本就能替代 [审阅 致命问题 4]。v2 只对**必须由我们持续运营的东西**收费：
- 语音纠错要持续调用识别和纠错模型，按用量有真实成本（模型里按每个付费用户每月 ¥4 计【假设】），系统自带的听写做不到"认出仓库里的函数名"。
- 手机看板和云端 agent 桥接需要我们的中转服务在线。
- Team 版卖给要过等保或 SOC2 审计的研发负责人和安全负责人，交付的是 SSO、可视化审计和 MCP 白名单，不是一个 JSON 文件。

### 3.2 为什么是 ¥499 / $99

- **海外 $99**：不能比罗技 $99.99 贵。我们拿来打差异化的，是罗技没有的三样东西：板载麦克风按住说话、✓ / ✗ 物理大键加高危操作二次确认、开箱就能跨 Claude Code / Codex / 国产 CLI 使用。日常成交价按 $95 计【假设：黑五、Prime Day 打到 $89，其余时间 $99】。
- **国内 ¥499**：和 D200 同价位，比 Vibe Key（¥269 起）贵 ¥230（早鸟 ¥399 贵 ¥130）。日常成交价按 ¥469 计【假设：618、双 11 打到 ¥449，其余时间 ¥499】。
- **众筹早鸟 ¥399 / $79** 是 D2 定的。摩点按 30% 超早鸟 ¥399 + 70% 早鸟 ¥449、均价 ¥434 计；Kickstarter 按 40% $79 + 60% $89、均价 $85 计【假设】。
- **砍掉 Lite 的账**：v1 的 Lite（¥299）在 1 万台规模下单台贡献只有国内 ¥53、海外 ¥28，还要单独花 ¥12 万模具认证费。入门需求交给免费软件 + 用户已有的设备。

### 4.3 单台账（元/台）

计算口径：

- 国内渠道【假设】：50% 天猫/京东（佣金加技术服务费 7%，投放 12%），50% 官网、小程序和社区（支付 1%，获客 5%）。免费软件用户是最便宜的获客来源，所以自营占比比 v1 高。

### 6.3 削减方案和补钱底线（D8）

**检查点和动作**：
1. **2027-07（开模扳机）**：全球付费订金（海外 $1 + 国内 ¥9.9）< 1,500 → 不开模、不众筹。团队降到 3 人，只做软件（个人 Pro + Team）。此时账上约 ¥150–160 万（第一期没花在模具和众筹上的部分），按"开模条件没达到"情景能撑到约 2029-01，期间要么用软件数据重新融资，要么把适配层卖给硬件厂。
2. **2028-06（零售第一个 618）**：零售销量低于计划 60% → 不招第 6 个人，回到 4 人，2029 年品牌投放减半，取消 v1.1 改模（也就是"悲观 + 削减"）。
3. **2029-06**：现金低于 ¥80 万（基准是 ¥89 万）→ 冻结招聘，品牌投放减半，旺季备货从 1.5 个月降到 1 个月。

**最少还要补多少钱**：
- 基准：**不用补**。想把现金低点抬到 ¥100 万，需要多 ¥65 万左右（可以用银行信用贷、深圳智能终端事后奖补，或者老股东的小额过桥 [china §5.3]）。
- 悲观 + 削减：到 2030 年 8 月缺 ¥35 万，而且看不到打平。**悲观情景下正确的做法不是补钱，而是在 2029 年 6 月做决定**：停止新的硬件批次，转成纯软件公司（Pro + Team + 给已有硬件的厂商做适配），或者把团队和适配层卖给硬件厂。
- 创始人拿市场薪资：要多补 ¥130 万。所以创始人低薪写进投资协议的预算里。

## 九、投资人会问的尖锐问题与回答

**1. 罗技 MX Keypad 卖 $99.99，9 个 LCD 键，原生支持 Claude Code 和 Codex，你们一个没品牌的初创公司凭什么卖 $99？**
罗技的价格是真的 [审阅 #4]，所以我们从 $129 降到 $99，不再比它贵。我们和它比三样它没有的东西：①板载麦克风，按住说话，语音直接发进选中的那个会话（MX Keypad 没有麦克风）；②✓ / ✗ 物理大键加高危操作二次确认，走 agent 的官方钩子直接回答，不是往前台窗口模拟按键；③国产 CLI（Qwen Code、CodeBuddy、Kimi、Trae）开箱就能用。如果开发者认为罗技已经够用，我们的免费软件也能驱动它的 SDK，用户留在我们的软件里，订阅照样能收。

**2. 你们的同名开源项目 puritysb/AgentDeck 已经免费上架优篮子插件商店，优篮子 D200 ¥500 多就能做状态显示和跳转。你们的软件凭什么收钱？**
所以 v2 删掉了"向优篮子收授权费"这条收入，也决定改名（D5）。状态显示和跳转本来就该免费，我们也免费。我们收钱的是对方做不到、并且需要持续运营的东西：懂代码的语音纠错、云端 agent 桥接、手机看板，以及 Team 版的 SSO、审计和 MCP 白名单。它们是否值钱，用 2028 年个人 Pro 的转化率（目标：周活 3% + 硬件用户 12%）来证明。

**3. Anthropic 自己的数据说，人工审批只拦下了 13.6% 的危险操作，自动分类器拦下了 89%。物理批准键是不是已经过时了？**
这组数据我们同意 [审阅 #5]，所以批准键不再是主卖点。日常低风险命令交给官方 auto mode；设备只拦**不可逆、跨边界**的操作（`git push`、生产环境、数据库写入、改密钥、合并 PR），要求人在物理上确认，相当于"agent 的硬件二次验证"（D3）。分类器拦下 89%，意味着还有 11% 漏过去，越不可逆的操作越需要人来兜底，而且人兜底时得看清楚是哪个会话、哪条命令。设备的主价值是"谁在等我 + 一键过去 + 不打字就能指挥"，审批只是其中一项。

**4. 重度用户都往云端 agent 迁（Cursor ARR $40 亿、75% 来自企业），本地钩子管不到云端，你们的场景是不是在缩小？**
是一个真实的风险 [审阅 #6]。v2 把会话键从"本地终端进程"扩展成"任务槽"：Cursor Cloud Agent、Codex 云任务、GitHub PR 等合并、CI 报错，也能占一个键、亮灯，按一下打开对应的网页或 diff。这部分做成个人 Pro 的"云端 agent 桥接"，是订阅收费的理由之一（D3、D4，P1 优先级）。

**5. OpenAI、Anthropic、罗技、Elgato 自己做怎么办？**
已经在做了：Codex Micro 只服务 Codex，Claude Buddy 只服务 Anthropic 自家产品（已支持 Claude Desktop 里的 Claude Code 和 Cowork [审阅 #12]），罗技做的是通用开发者键盘。大厂不会做"同时支持竞争对手"的设备，中立是我们的位置。最大的威胁是罗技或 Elgato 把跨 agent 审批做成官方插件。我们的应对是：软件本来就支持他们的硬件，用户的模板、策略和审计记录都留在我们这里。

**6. 硬件 6 个月就会被抄，护城河在哪？**
硬件没有护城河，这点我们承认。护城河是：①各家 agent 的钩子每月都在变，持续维护 8 家以上的适配是工程活，我们已经踩过 `idle_prompt` 误报、Codex 只有 `notify` 等坑；②跨厂商的高危操作策略和语音纠错词库（这不是数据飞轮，分级准确率我们不和官方分类器比）；③Team 版的策略、审计和 SSO 集成，换掉的成本高。第③条要到 Team 有付费客户才成立，现在还是假设。

**7. 三年收入 ¥1,043 万，扣渠道履约后的单台净毛利率 28%（出厂产品毛利率国内 38% / 海外 52%），这是不是一门小生意？**
如果只看硬件，是。所以我们不按"高增长硬件公司"来花钱，而是按 default alive 来设计：一轮 ¥500 万，2030 年 5 月起经营利润持续为正，不需要 Pre-A。值得投的部分是上行空间：Team 版能卖给要过审计的研发团队，跨 agent 控制层有机会成为开发者桌面上的中立标准。基准里软件收入 2029 年 ¥62 万、2030 年 ¥144 万，我们不包装成平台故事，用试点数据说话。

**8. 为什么毛利率不到审阅要求的 42%？**
按现在没有报价的估算，1 万台档国内产品毛利率 38%、海外 52%。国内要到 42%，含预留的 BOM 必须 ≤ ¥202（现在估 ¥220）。这条写进了 D7④ 报价的合格线。报价达标后，现金低点从 ¥35.5 万升到 ¥86.5 万。达不到的话，国内超早鸟就取消 ¥399 档，日常价不打折。

**9. 学生团队没有量产经验，怎么保证交付？**
①只做一款、只开一套模具；②有 1,500 个订金才开模；③第一个招聘的人就是有量产经验的硬件结构/供应链工程师；④交付时间放在众筹结束后 4 个月；⑤模具和贴片交给有键盘量产经验的深圳代工厂，我们只做设计和测试治具。如果有条件，优先进 XbotPark 这类能补供应链短板的体系 [审阅 §六]。

**10. CtrlVibe 在 Kickstarter 上只有 59 个支持者，你们凭什么能卖 1,500 台？**
CtrlVibe 是冷启动，上线前没有用户池。我们在众筹前先有：免费软件周活 2,000、1,500 个付费早鸟订金用户（海外 $1 + 国内 ¥9.9 合计）。按审阅给的经验值，1,500 个订金对应首日 500 台以上；我们基准 Kickstarter 900 台 + 摩点 600 台。订金达不到 1,500 就不开模、不众筹，最多损失 ¥6.4 万的投放费。

**11. 个人 Pro ¥19/月，用户为什么不用系统自带的听写？**
系统听写不认识你仓库里的函数名、文件名和技术黑话，中英混说的时候错误率很高；Pro 的语音纠错会读取当前会话的上下文（文件名、符号表）来纠正识别结果。另外两项（手机看板、云端 agent 桥接）系统里根本没有。我们只按 3% 的周活转化率来估，并在 2028-06 检查点验证。

**12. 为什么要 ¥500 万？如果 18 个月后失败了，钱花在哪？**
钱分两期。第一期 ¥250 万用来做验证、DVT、订金测试，以及订金达标后 2027-08 的开模（¥12 万）；如果订金到不了 1,500，第二期不到账，也不开模，公司带着约 ¥150–160 万转成纯软件。第二期到账后，钱的 36% 是人、4% 是模具和认证，2028 年末还留 ¥156 万。最坏的情况（悲观 + 削减），我们会在 2029 年 6 月决定停止硬件批次，不会把钱全压在库存上。

**13. 国内开发者会花 ¥499 买外设吗？优篮子 Vibe Key 只卖 ¥269。**
不知道，这是目前最大的数据缺口：开发者外设的付费意愿调研没有找到 [market §4]。所以基准里国内只占零售销量的 50–70%、众筹的 40%，用摩点 600 台的目标来测；同时用免费软件支持用户已有的 Vibe Key 和 D200，不强推硬件。国内用户更愿意为 coding 套餐付钱（Kimi ¥99 起/月 [china §1]），和国产 agent 厂商捆绑可能比纯卖设备更有效。

## 十、模型里最不确定的 7 个假设（按影响排序）

4. **零售销量**：2029 年 1.2 万台。悲观情景是基准的 45%，那种情况下不能再靠硬件活下去。

7. **汇率 7.1**：海外占零售的 30–50%，汇率每变 5%，海外毛利额也跟着变约 5%。
