| | 4×4 键盘（每键 RGB） | v2 长条屏 + 6 会话键 + 3 大键 |
|---|---|---|
| 好处 | 手上现成，今天就能自用；有现成宏键盘方案可改，量产最便宜最快；8 会话键 + 8 功能键排得下；"Ctrl + 会话键 = 模板指令"的双用设计照样成立；对称 | 屏幕直接显示"在等哪条命令"，高危确认最直观；外观有记忆点，路演好讲 |

**判断：第一版用 4×4 + 每键 RGB + 电脑浮窗当屏幕。** 自用和试用数据证明"光看灯不够、必须在设备上看命令"，再加长条屏。屏幕是升级件，不是起步门槛。PRD 第 7 节已标"形态待定"，等你拍板。

### 4. Windows 迁到 Mac 会遇到什么

- 借来的 CXT 键盘用了 Zadig 换驱动的办法，Mac 上没有这一套；**我们自己做的设备不需要换驱动**，Windows 和 Mac 都即插即用。
- Mac 上切窗口要用户授权"辅助功能"，读键盘要授权"输入监控"，语音走系统听写。
- 代码已经按平台分层（`hub_desktop.py` / `hub_desktop_mac.py`）。你没有 Mac 也没关系：Windows 版自用跑顺后，借一台 Mac 集中调 1–2 天。

### 5. USB 还是蓝牙、Type-C 还是 USB

- **Mac 完全支持 USB。** 新 Mac 只有 Type-C 口，设备用 Type-C 线插上即可，键盘类设备不用装驱动。不存在"Mac 必须蓝牙"。
- Type-C 是**接口形状**，USB 是**协议**，两者不冲突：设备用 Type-C 口、走 USB 协议。
- 蓝牙是无线，不占接口。ESP32-S3 自带蓝牙，以后做无线版硬件不用改。第一版建议只做 Type-C 有线：不用电池、不用配对、延迟稳定。

### 6. Codex 宠物、Claude 侧栏

Codex 桌面版 2026-05 上线"宠物"浮层：气泡显示运行中 / 等你批准 / 可以验收，并发系统通知；也有用户嫌它只是装饰，要求换成任务看板。Claude 桌面版左侧会话栏也会标谁在等你。

结论：**"告诉你谁在等"已经不够当卖点**。设备要赢在三点：同时看全所有家的 agent；不切窗口就能批；高危操作必须物理确认。已写进 PRD 第 1 节。

### 8. 键盘灯效

**结论：现在还不能控制，但不是硬件不行，是缺协议。**（详见 `research/deck-light.md`，全程没往键盘发任何东西）

- 厂商教程写了"每颗键可以单独配色"，说明硬件大概率支持单键 RGB。
- 但网页（47.92.105.50）只是下载页，没有驱动代码；旧 VIA-C 的灯光命令走的是另一个接口（0xFF60），而这把键盘是 0xFF00，硬套可能让它进 bootloader 或清掉键位。
- 要拿到真协议，有两条路，都要你来：
  1. **抓包（推荐）**：装 Wireshark + USBPcap，打开厂商的 CXT Hub 客户端改几次颜色，我们录下真正发出去的报文。最可靠，看到的就是这把键盘真认的命令。
  2. **拆客户端**：你从下载页的网盘下 CXT Hub 的 Windows 安装包，我只解包读代码、不运行。
- 拿不到协议之前，状态用托盘图标颜色 + 浮窗 + 1602 屏显示。

> 需要你决定：走哪条路？

> 批注（11-19）：那就试试抓包。意思是抓包，然后用包的信息控制灯效？

> 回复：对。你在 CXT Hub 里改颜色时，客户端会给键盘发几条 USB 报文。我们把这几条录下来，找出"第几颗键、什么颜色"分别写在哪几个字节，之后 AgentDeck 自己发同样格式的报文：哪个 agent 在等你，对应的键就亮琥珀色。用的是厂商客户端本来就会发的命令，不会把键盘搞坏。
>
> 另外查到：CXT Hub 已经装在你电脑上，但它的代码做了加密打包，所以不去拆它，只抓包。
>
> **抓包步骤（大约 10 分钟）：**
> 1. 装 Wireshark：官网 wireshark.org 下载 Windows 安装包。安装时勾上 **USBPcap**，装完重启电脑。
> 2. 右键托盘退出 AgentDeck，免得按键报文混进来。
> 3. 打开 Wireshark，双击 `USBPcap1`（有好几个的话，插拔键盘看哪个跳数据，就选哪个）开始录。
> 4. 打开 CXT Hub，按这个顺序改，每步之间停 3 秒：
>    - 第 1 颗键改成红色
>    - 再改成绿色
>    - 再改成蓝色
>    - 第 2 颗键改成红色
>    - 整体亮度调到最低
>    - 再调到最高
> 5. 停止录制，"文件 → 另存为"，保存到 `D:\desk\hardware\h1\research\capture\light.pcapng`。

### 9. 软件做成 exe

**做好了**：`dist\AgentDeck\AgentDeck.exe`。像键盘驱动一样常驻托盘，双击后 hub、宏键盘、浮窗一起启动；托盘右键能看会话、看键位、看诊断、把钩子装进项目、开机自启。整个 `dist\AgentDeck\` 文件夹要放在一起，挪位置后要重新"安装到项目"。

用它开发的三步：托盘右键"安装到项目…"选你的项目文件夹 → 在那个项目里开 Codex 输入 `/hooks` 信任（Claude 不用）→ 正常干活，要批准时按第 2 排第 1 颗（✓）或第 2 颗（✗）。
