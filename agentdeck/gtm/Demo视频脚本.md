## 拍摄原则

1. **不造假**：只拍真实运行的软件和真实样机。没做完的功能要么不拍、要么按"降级拍法"换掉，不用后期合成假装它能用。
2. 概念渲染图只能出现在片尾，并打字幕"概念设计"。
3. 画面一直是**分屏**：左边俯拍手和设备，右边录电脑桌面。观众要能同时看到"手按了什么"和"屏幕上发生了什么"。
4. 全程手不碰主键盘和鼠标，只有 0:25 那一下用鼠标把焦点点回记事本，要让观众看清。

## 状态标记

| 标记 | 含义 |

## 汇总：开拍前要做完的

**必须做完（没有降级办法）：**
1. Demo 样机硬件 + 固件 + 主机协议（06 第 13.2 节 #11）
2. 物理键 → 中枢在实体键上验证（#12）
3. `PermissionRequest` 在真实 Claude Code 会话里验证，前台记事本不漏字（#3）

**做完更好，没做完按降级拍：**
- tmux pane 跳转（#10）→ 改多标签或删镜头 3
- 长按 ✗ 打断（#7）→ 单按拒绝
- Qwen Code / CodeBuddy 适配（#14）→ 换 Claude Code，不说"国产"
- 按住说话锁定会话（#15）→ 删"抢焦点"段
- 热词纠错（#16）→ 改台词
- 按键到钩子返回的耗时记录（#18）→ 视频里不说"毫秒级"

**已经可以拍的：** 窗口切前台（Windows）、L2 二次确认、L3 锁死、拒绝、中枢离线回退（可做花絮：拔掉中枢，agent 回到原生提示）。
