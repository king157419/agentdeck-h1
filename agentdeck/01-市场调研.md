## 一、市场定义（v2 修订）

**一句话：我们卖的是"跨本地与云端 AI 编码 agent 的桌面物理调度台与硬件安全闸门"——以 Codex Micro 为形态标杆，介于宏键盘和 Stream Deck 之间的一个新细分，2026 年刚被大厂做成品类。**

| 层级 | 范围 | 说明 |
|---|---|---|
| 核心市场 | 同时跑多个本地 CLI 或云端异步 AI 编码 agent 的开发者购买的物理控制外设 | 我们的主战场（前 18 个月聚焦单款主力机） |
| 相邻市场 | Stream Deck / Logitech MX Keypad 类可编程控制台、宏键盘 | 价格锚点（$99.99）和免费软件获客入口 |
| 延伸市场 | 个人 Pro 订阅（代码语音纠错、手机看板、云端桥接）+ 企业 Team 版（SSO、合规仪表盘、MCP 工具白名单） | 经常性软件收入与长期护城河（D4） |

相邻市场的量级：Elgato 所在的 Corsair 外设分部 FY2025 收入 4.72 亿美元 [1]；机械键盘市场各机构估计 15～29 亿美元，口径差异大 [2]；**"宏键盘"单独的市场规模没有可信报告**。

## 二、用户分层与三个画像（v2 修订）

**结论：先用免费软件 + 单款主力机打透"并行派"个人开发者（海外 + 国内），同步验证个人 Pro 订阅，企业 Team 版是第二步。**

| 画像 | 是谁 | 典型一天 | 最痛的点 | 愿付价格（v2 对齐 D2/D4） |
|---|---|---|---|---|
| **A. 并行派开发者（海外）** | 独立开发者、初创公司工程师，同时开 5～10 个本地 Claude Code / Codex 及云端 Cursor Cloud Agent 会话 | Claude Code 作者本人在本地终端跑 5 个、网页端再跑 5～10 个，靠系统通知找"谁在等输入" [3] | 不知道哪个本地或云端 agent 卡住了；来回切窗口、敲错焦点 | **单机 $99（早鸟 $79）** + 可选个人 Pro $3.99/月（卡在罗技 MX Keypad $99.99、VibeKeys Max $99 以内）[4][5][53] |
| **B. 团队技术负责人（企业）** | 管 5～50 人研发团队、要对 agent 越权修改与代码合规负责的人 | 60% 的 agent 使用者会阻止未经批准的系统改动，63% 很少或从不让 agent 完全自主 [6] | 人类手动盲批了 97% 的提示 [57]；高危不可逆动作需物理防呆 + 企业级 SSO/MCP 白名单审计 | **硬件 + Team 订阅（¥39～59/人/月）**（D4） |
| **C. 国内开发者** | 用"Claude Code + 国产模型（GLM / Kimi / DeepSeek）"，或用 Trae、CodeBuddy、Qwen Code 的人 | 在 B 站学 Claude Code 教程（单集播放达 15.7 万量级）[7]；Codex Micro 中文页缺货买不到 [8] | Codex Micro 买不到且不支持国产 CLI；国内低价设备要么无屏（AU05）、要么无麦且为薄膜键（D200） | **单机 ¥499（早鸟 ¥399）** + 可选个人 Pro ¥19/月（对比国内锚点 AU05 ¥269～299、D200 ¥298～598）[9][55] |

**三个画像的购买触发点：**
- **A 并行派：** 某一天发现"有个 agent 已经等了我 20 分钟"，或误在别的窗口敲回车闯了祸。原话见 issue #36885："瓶颈不再是 Claude 的速度，而是人发现 Claude 在等" [49]。他们动手能力强，产品必须做到"开箱即用，比自己配插件或焊板子省事得多"。
- **B 技术负责人：** 团队里出现一次"agent 强推分支 / 误连生产环境写库"事故，或公司过等保/SOC2 要求对 AI 工具调用留痕与白名单管控。他们买的不是键盘，是"高危操作物理闸门 + 企业合规仪表盘"。
- **C 国内开发者：** 看到 Codex Micro 的新闻却买不到，或者嫌拼凑两台设备麻烦。他们对价格敏感，对"一块全管海内外/国产 agent + 机械轴手感 + 中文懂代码语音输入"有明确偏好。

**暂不优先：** 因手腕劳损（RSI）而需要语音输入的人群。相关说法主要来自厂商营销，没找到可靠的第一人称证据 [10]。

## 四、市场规模（TAM / SAM / SOM）（v2 修订）

**结论：这是一个"几亿美元总盘子、三年硬件拿一千多万到三四千万人民币"的细分市场，不要写成上百亿；VC 级想象空间必须靠软件层（跨端调度 + 个人 Pro / 企业 Team 订阅）打开。**

### 全球（含中国开发者，海外渠道定价）（v2 修订）

假设（仅更新受 D9 人口口径与 D2 单款定价影响的数字，其余比例假设保持不变）：
- **基础人口更新**：取 JetBrains **2026 年最新口径"全球专业开发者约 2,200 万"**（仅计受雇职业开发者，2024 年为 1,960 万、2025 年为 2,080 万）[22]，不取含学生和业余爱好者的 SlashData 4,840 万。
- 用 agent 的比例（不变）：保守 31%（Stack Overflow 2025）[23]，乐观 59%（Stack Overflow 2026-04 小样本调研，n=1,100）[6]，基准取 40%【估算】。
- 多 agent 比例（不变）：33%（同一调研里 17% 分工使用 + 16% 协同使用）[6]。
- **硬件单价更新（对齐 D2）**：前 18 个月砍掉 Lite、推迟 Pro，只做一款主力机，海外标准零售价 **$99**（众筹早鸟 $79；下表按标准零售价 $99 测算，并在表后列出维持原初稿 $115 混合均价的纯人口变动对照值）。

| 层级 | 定义 | 算式（v2 展示） | 结果（v2） |
|---|---|---|---|
| agent 使用者 | 专业开发者 × 40% | 2,200 万 × 40%（区间 × 31%～59%） | **880 万人**（区间 682 万～1,298 万） |
| **TAM** | 每个 agent 使用者买一台 | 880 万 × $99（区间 682 万～1,298 万 × $99） | **约 8.7 亿美元**（区间 6.8 亿～12.9 亿美元） |
| 多 agent 使用者 | agent 使用者 × 33% | 880 万 × 33% | **约 290 万人**（精确值 290.4 万） |
| **SAM** | 多 agent 使用者买一台 | 290.4 万 × $99 | **约 2.9 亿美元**（2.875 亿） |
| 可触达部分 | 桌面办公、愿为外设付费，**纯假设 50%** | 290.4 万 × 50% ；× $99 | **约 145 万人**（145.2 万），**约 1.4 亿美元** |
| **SOM（3 年）** | 可触达人群的 1%～3% | 145.2 万 × 1%～3% ；× $99 | **1.45 万～4.36 万台（约 1.5 万～4.4 万台），约 144 万～431 万美元** |

> **口径拆解对照：** 上表同时反映了 **D9（开发者人口 2,080 万 → 2,200 万，+5.8%）** 与 **D2（单款定价 $99，替代原初稿 $59/$129/$199 混合均价 $115，-13.9%）**。若仅更新开发者人口至 2,200 万而保持原 $115 均价不变，则算式结果为：**TAM = 880 万 × $115 ≈ 10.1 亿美元**（区间 `682 万 × $115 ≈ 7.8 亿` ～ `1,298 万 × $115 ≈ 14.9 亿美元`），**SAM = 290.4 万 × $115 ≈ 3.3 亿美元**，可触达 `145.2 万 × $115 ≈ 1.7 亿美元`，**3 年 SOM = 1.45 万～4.36 万台、约 167 万～501 万美元**【估算】。

### 中国（国内渠道定价，保持单独测算）（v2 修订）

假设：
- 中国软件开发者约 **940 万**，已查实出处为工信部负责人在 **2024 年 12 月武汉"2024 开放原子开发者大会"**上正式公布的数据（含开源与广义软件从业者，口径宽于 JetBrains 受雇职业开发者窄口径）[24][50]。因其相当于全球窄口径的 43%，为防双重计算或口径污染，**中国部分保持单独测算、绝不与全球数字相加**。
- 旁证（不变）：Trae 自报注册 600 万+、月活 160 万 [25]。
- 用 agent 的比例（不变）：没有国内权威数据，取 35%【估算】。
- 多 agent 比例（不变）：取 20%【估算】，低于海外的 33%，因为国产工具多为 IDE 插件形态，且海外调研样本偏爱 AI。
- **硬件单价更新（对齐 D2）**：国内单款主力机标准零售价 **¥499**（众筹早鸟 ¥399；替代原初稿 ¥299/¥599/¥999 混合均价 ¥550）。

| 层级 | 算式（v2 展示） | 结果（v2） |
|---|---|---|
| agent 使用者 | 940 万 × 35% | 约 329 万人（不变） |
| **TAM** | 329 万 × ¥499 | **约 16.4 亿元**（原 ¥550 均价下为 18.1 亿元） |
| 多 agent 使用者 | 329 万 × 20% | 约 66 万人（65.8 万，不变） |
| **SAM** | 65.8 万 × ¥499 | **约 3.3 亿元**（原 ¥550 均价下为 3.6 亿元） |
| 可触达（50%，纯假设） | 65.8 万 × 50% ；× ¥499 | 约 33 万人（32.9 万），**约 1.6 亿元** |
| **SOM（3 年）** | 32.9 万 × 1%～3% ；× ¥499 | **3,300～9,900 台，约 165 万～494 万元** |

### 合计与校验（v2 修订）

- **三年硬件 SOM 合计**：台数 `1.45 万 + 0.33 万` 至 `4.36 万 + 0.99 万` = **约 1.8 万～5.4 万台**；按 v2 单款标价（海外按 08 基准汇率 1 美元 = 7.1 元折算：`144 万～431 万美元 × 7.1 ≈ 1,022 万～3,060 万元` + 国内 `165 万～494 万元`）合计 **约 1,200 万～3,550 万元人民币**【估算】（若按原 $115 / ¥550 均价则约 1,370 万～4,100 万元）。**个人 Pro 与企业 Team 软件订阅收入未计入上述硬件盘子。**
- 校验 1：**CtrlVibe 在 Kickstarter 主场众筹仅获 59 人支持**（PledgeBox 仅为其赛后履约工具）[26][56]，Prolo Ring 有 2,865 人 [27]，国内摩点键盘类成功项目 AuraFlow Tap 557 人 [28]——证明无软件蓄水的硬件冷启动只有"数十到数百台"，三年做到数万台必须靠免费软件先圈住重度用户。
- 校验 2：Stream Deck 只是 Corsair 4.72 亿美元外设分部里的一部分 [1]，我们的三年硬件 SOM 在数百万美元量级符合客观常识。

**最敏感的假设：** 多 agent 比例。如果真实值只有 15%（海外），SAM 约减半。这个数据目前只来自一份 1,100 人的小样本 [6]。

**结论：2026 年同时发生了四件事——agent 迈入数十亿美元收入规模、"多开"从本机终端扩展到云端异步容器、各家开放钩子并开启默认 Auto Mode、硬件巨头正式定义品类。**

| 趋势 | 证据 | 来源 |
|---|---|---|
| agent 用户快速增长 | 用 agent 的开发者：31%（2025）→ 59%（2026-04 小样本）；工作中用 Claude Code：18%（2026-01）→ 39%（2026 年中） | [23][6][29] |
| **收入规模爆发至数十亿美元级** | Claude Code 年化收入超 **25 亿美元**（2026-02，Anthropic 官方）[30]；**Cursor（Anysphere）年化收入从 2026-02 的 20 亿美元一路跃升至 2026-06 突破 40 亿美元（$4B ARR，企业客户贡献约 75% / 约 26 亿美元），并于 8 月完成被 SpaceX 约 600 亿美元收购**【二手创投数据库与媒体报道，非审计财报】[51]；Codex 周活 2026-06 超 500 万【待核实，二手】[31] | [30][51][31] |
| **"多开"向"本地 + 云端异步并行"迁移** | Cursor 爆发的核心催化剂是 **Cloud Agents**（在隔离云端 VM 中异步执行长任务，支持从网页 `cursor.com/agents`、Slack、GitHub、Linear 触发并自动提 PR）及 Cursor 3 `Agents Window`（本地、worktree、云端并行）[32][52]；GitHub Copilot coding agent 在数月内创建超 100 万个 PR [52] | [32][51][52] |
| 审批接口开放 + Auto Mode 普及 | Claude Code、Codex 有 `PermissionRequest` 钩子；国产 CodeBuddy、Qwen Code、Kimi Code 也有同类事件；同时 Claude Code 自 2026-08 起默认开启 Auto Mode（AI 分类器拦下 89% 危险命令） | [33][34][35][36][37][57] |
| 品类被大厂定义且定下 $99.99 锚点 | 2026 年 5 月～9 月，Anthropic（BLE 伴侣）、OpenAI（Codex Micro $230）、Logitech（MX Keypad $99.99）、Ulanzi（AU05 Vibe Key ¥269）密集出手 | [12][11][53][9][54] |

### 深度研判：Cursor $4B ARR 与"云端 agent 迁移趋势"对我们的影响（v2 修订）

Cursor 突破 $4B ARR（且 75% 来自企业）[51] 对 AgentDeck 是一个必须正视的**双向分水岭信号**：
1. **正面催化（把并行上限从 3 个推高到 10 个）**：过去受本机 CPU/内存与目录冲突限制，普通开发者本机最多开 2～3 个 CLI；Cloud Agents 与 worktree 普及后，工程师习惯把修 bug、补测试、重构分发给 5～10 个后台云端与本地会话异步跑——**人类的注意力切换、待审队列积压与最终合入把关成了真正的系统瓶颈**。
2. **致命风险（掏空"纯本地进程切换器"）**：云端异步 agent 跑在远程容器里，**不在本机产生终端进程句柄，也不会触发本机 `127.0.0.1` 的命令行 hook**。如果 AgentDeck 只是一块"切本机终端窗口 + 替本机 CLI 按回车"的外设，重度用户越往企业级云端工作流升级，设备闲置率反而越高。
3. **我们的战略调整（直接落地为 D3 与 D4）**：
   - **槽位云端化（D3，P1 优先级）**：将 6 个会话键从"本机终端槽"升级为**"本地 CLI + 云端异步任务统一槽"**——通过 Webhook / API 轮询接入 Cursor Cloud Agents、Codex 云任务、GitHub PR 待 Review 与 CI 报错阻塞；云端任务卡住或跑完待检视时，长条屏对应分栏同样亮起琥珀色摘要，一按直接唤起浏览器对应云端会话或 PR Diff 页。
   - **订阅商业化闭环（D4）**：云端任务状态桥接与离开工位时的手机只读看板天然涉及跨端同步，顺理成章构成**个人 Pro 订阅（¥19/月，$3.99/月）**与**企业 Team 版（¥39–59/人/月）**的高粘性付费抓手；而本地高危动作（如把云端代码拉回后 `git push`、合并线上生产 PR、生产环境 `ssh/kubectl`）则由实体硬件执行最后一道物理二次确认。

**窗口在收窄：** 罗技 MX Keypad（$99.99）[53]、Keychron（$34.99）[38] 和优篮子 AU05（¥269）/ D200（¥298+）[9][55] 已经封死高价与纯低端空间。我们大约有 **6～12 个月**建立"跨本地/云端/国产全生态 + 高危物理二次确权"的心智【估算】。

## 六、中国市场（v2 修订）

**结论：国内不是空白，优篮子已卡住"无屏带麦"和"薄膜屏+免费同名插件"两个位置，但仍缺一块"真机械轴 + 分槽屏 + 板载麦 + 底层直答防呆"的完整单品。**

- **已有对手更正（对齐 D9）：**
  1. **Ulanzi 优篮子 AU05 Vibe Key**：¥269～299，6 颗矮轴键 + 旋钮 + 全向麦克风，CNC 铝壳，**没有显示屏** [9][39]。**更正原初稿误判：它并非锁死腾讯 WorkBuddy 生态**——WorkBuddy 仅为国内联名宣发入口，底层走通用 Ulanzi Studio，支持自由映射 Claude Code、Codex、千问、豆包等 [54]。它是国内无屏语音小键盘的价格锚点。
  2. **Ulanzi D200 系列 + 免费同名插件**：D200（13 键薄膜 LCD，国内日常 ¥298～598，无麦克风）官方插件商店（`ugc.ulanzistudio.com`）已免费上架同名开源项目 `puritysb/AgentDeck` [55]——直接证伪了向优篮子收 OEM 授权费的设想（D4 已删除该收入项），也倒逼我们路演前改名（D5）。
