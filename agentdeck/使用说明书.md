AgentDeck 使用说明书（CXT 宏键盘版，Windows）
版本：2026-11-20｜适用：`dist\AgentDeck\AgentDeck.exe`

## 它是什么
AgentDeck 是 Claude Code 和 Codex 的遥控器。agent 要你批准命令时，屏幕角落的浮窗会显示那条命令，你在宏键盘上按 ✓ 或 ✗ 就行，不用切窗口找按钮。同时开好几个 agent 时，浮窗能看出谁在跑、谁在等你，还显示每个会话最新的一句话；按一颗键就能跳过去，转旋钮就能翻看它的输出、回答它的提问。

宏键盘没插上时，AgentDeck 不拦批准：agent 自己的确认框马上弹出来，你照常在 app 里点。插上宏键盘，它才接管批准，用键盘按 ✓ 或 ✗。

它不替代键鼠：写长需求、看 diff、选中文字问 agent，还是用键鼠。键盘上没有屏幕，命令内容要看电脑上的浮窗。

## 第一次使用（约 1 分钟）
1. 把整个 `dist\AgentDeck\` 文件夹放在固定位置，以后别挪。挪了也没关系，下次启动会自动修好路径。
2. 双击 `AgentDeck.exe`，在弹出的窗口里点"开始使用"。它会做三件事：
   - 让所有项目的 Claude Code 和 Codex 都接入；
   - 换掉旧版 1602 钩子；
   - 设置开机自启（用 Windows 的"任务计划程序"，任务名 AgentDeck，登录时启动）。
3. 如果你用 Codex：在 Codex 里输入 `/hooks`，选信任。只需要一次，这是 Codex 的安全规定。Claude 不用做这步。
4. 已经开着的 agent 会话要重开一次，新开的会话自动生效。

之后每次开机登录都会自动运行。再双击一次 `AgentDeck.exe`，不会开第二个，而是把状态窗口打开。

### 托盘图标在哪（Windows 11）
图标默认藏在任务栏右下角时钟旁边的 ^ 里。点 ^，就能看到 AgentDeck 的图标。想让它一直露在任务栏上：把图标从 ^ 的小窗里拖到任务栏上放下。

### 状态窗口里的"宏键盘"一行
状态窗口有一行"宏键盘"，写着键盘有没有插上、用什么方式读键（USB 直读 / Raw Input / 未连接）。没插键盘时显示未连接，这是正常的，不影响 agent 使用。

## 键位
宏键盘有 4 列 5 排共 20 颗键，加 4 个旋钮。**键帽上印的字不一定是它实际发出的键**，所以找键一律按位置：从上往下数第几排，从左往右数第几颗；旋钮从左往右是 1 到 4。下面的表是逐颗实测出来的。

一眼看全（每格：实际发出的键 / 功能）：

| | 第 1 颗 | 第 2 颗 | 第 3 颗 | 第 4 颗 |
|---|---|---|---|---|
| 1 排 | **E**<br>会话 1 | **B**<br>会话 2 | **Ctrl+Z**<br>会话 3 | **空格**<br>打断 |
| 2 排 | **G**<br>✓ 批准 | **Ctrl+F**<br>✗ 拒绝 | **H**<br>语音输入 | **Alt**<br>不绑定 |
| 3 排 | **L**<br>截图 | **M**<br>继续 | **Ctrl+T**<br>跑测试 | **Ctrl+D**<br>总结 ⚠ |
| 4 排 | **Ctrl**<br>不绑定 | **Shift**<br>不绑定 | **U**<br>提交 | **X**<br>下一个会话 |
| 5 排 | **Tab**<br>跳到等你的 | **Ctrl+C**<br>不绑定 ⚠ | **Ctrl+V**<br>不绑定 ⚠ | **P**<br>上一个会话 |

| 位置 | 键盘发出的键 | 功能 |

| 第 1 排第 1 颗 | E | 跳到会话 1 |
| 第 1 排第 2 颗 | B | 跳到会话 2 |
| 第 1 排第 3 颗 | Ctrl+Z | 跳到会话 3 |
| 第 1 排第 4 颗 | 空格 | 打断当前会话（相当于按 Esc） |
| 第 2 排第 1 颗 | G | ✓ 批准 |
| 第 2 排第 2 颗 | Ctrl+F | ✗ 拒绝 |
| 第 2 排第 3 颗 | H | 语音输入：默认按住说话；可选单点 |
| 第 2 排第 4 颗 | Alt（只发修饰键，没有字母） | 不绑定（没装 WinUSB 时单按会漏进窗口，可能让窗口的菜单栏获得焦点） |
| 第 3 排第 1 颗 | L | 截图 |

| 第 4 排第 3 颗 | U | 发送"提交" |
| 第 4 排第 4 颗 | X | 下一个会话 |
| 第 5 排第 1 颗 | Tab | 跳到下一个在等你的会话 |

| 第 5 排第 4 颗 | P | 上一个会话 |
| 旋钮 1 转动 | 顺时针 F / 逆时针 S | 切窗口：顺时针 Alt+Tab，逆时针 Alt+Shift+Tab；停转 900 毫秒后选定窗口 |
| 旋钮 1 按下 | L | 截图 |
| 旋钮 2 转动 | 顺时针 R / 逆时针 P | 选会话：按最近活动排序，顺时针下一个，逆时针上一个 |
| 旋钮 2 按下 | Q | 按下切过去：直接跳到所选 Claude 会话，其他会话调到对应窗口；同时显示浮窗 |
| 旋钮 3 转动 | - / = | 滚动所选会话的窗口：发 - 的方向往下看新内容，发 = 的方向往上翻（哪边是 - 还没测准） |
| 旋钮 3 按下 | V | 直接滚到底 |
| 旋钮 4 转动 | ] / [ | 下 / 上方向键：agent 提问时换选项 |
| 旋钮 4 按下 | C | 回车：提交选项，或把语音说完的话发出去 |

Alt、Ctrl、Shift 三颗只发修饰键，默认不绑定，平时别按；按住它们再按别的键，那颗键会被当成组合键，不起作用。

托盘右键选"键位"，能看到这张图。上表是默认键位（第 8 版）。没改过的 v7 键位文件会在启动时自动换成第 8 版，旧文件留作 `hub_keys.json.bak-v7`；更早的 v3-v6 默认文件也会升级并按原版本备份。你自己改过的键位文件不会被动。

每次按键，浮窗会写出物理位置和结果，例如“旋钮 1 顺时针 → 下一个窗口”“第 2 排第 1 颗 → 已批准”。有些位置发同一个键码，就会一起显示，例如“第 5 排第 4 颗 / 旋钮 2 逆时针”；日志里的按键记录也有这个名字。

"发送'继续'"这类键，会把一句写好的话粘贴进当前会话再回车。这些话在 `%USERPROFILE%\.agentdeck\hub_prompts.json` 里，可以改。

## 日常怎么用

### 批准命令
前提：只有宏键盘插着的时候，AgentDeck 才会扣住批准请求等你按键。没插键盘，它马上放手，浮窗那一行写"在应用里批准"，你到 Claude 或 Codex 自己的窗口里点就行。Codex 要等 AgentDeck 回话才显示自己的确认框，所以没插键盘时不会被卡住。

插着键盘时：
1. agent 要执行需要批准的命令时，浮窗会弹出来：上面是会话列表，下面是那条命令。
2. 看清命令，按 G（✓，第 2 排第 1 颗）放行，或按 Ctrl+F（✗，第 2 排第 2 颗）拒绝。
3. 危险命令（强推、删目录等）浮窗会标红并提示"再按一次"，1.5 秒内再按一次 ✓ 才放行。
4. 最危险的一类会直接锁住，键盘批准不了，要回终端处理。这是故意的。
5. 防误触：命令刚出现的 0.3 秒内按键不算数，免得你按到上一条去。

### 看谁在等你、它说了什么
浮窗每行是一个会话，按最近活动从新到旧排列。Claude 会话显示 Claude 侧栏里的标题；没有读到标题时才用文件夹名，长标题会截短。等你的会话名字变成琥珀色，后面写着"等你"，但不会插队；正在跑的会话，名字后面用灰字写它在用什么工具。

会话列表下面是一块"最新一句话"：所选会话（没选就是第一个等你的会话）最后说的话、你最后发的话或它的提问，最多 8 行，标题写着第几号、哪种消息、多久之前。浮窗在显示这个会话的待批命令时，先显示命令。

右边的点表示状态：

| 颜色 | 状态 |
|---|---|
| 绿 | 在跑 |
| 琥珀 | 等你批准或回复 |
| 蓝 | 做完了，等你验收 |
| 红 | 出错 |
| 灰 | 空闲 |

按 Tab（第 5 排第 1 颗）跳到下一个等你的会话。

### 切换会话
- **切窗口**：转旋钮 1，顺时针相当于 Alt+Tab，逆时针相当于 Alt+Shift+Tab。连续转动时保留 Windows 的切窗列表，每格移动一次；停转 900 毫秒自动松开 Alt，选定窗口。按其他功能键或退出 AgentDeck 时也会先松开 Alt。
- **选会话 / 按下切过去**：旋钮 2 按最近活动从新到旧选会话，顺时针下一个，逆时针上一个，首尾循环；X / P 两颗键也能前后选。开始转动时，会先读一次 Claude 当前打开的会话，若它也在列表里，就从它开始选；停下超过 5 秒再转，会重新从它开始。
- **直接跳到 Claude 会话**：选好后按下旋钮 2。AgentDeck 把 Claude 调到前台，直接点侧栏中同标题的会话并确认，提示“已切到：标题”，不用先用鼠标点 Claude。侧栏找不到标题或没能确认时，只把窗口调到前台，提示“Claude 侧栏里没找到：标题”。同标题有多个时打开侧栏第一个。
- **固定槽位**：第 1 排前三颗（E / B / Ctrl+Z）仍选会话槽位 1-3；槽号不随最近活动排序变化。Codex、终端等会话仍激活对应窗口。窗口关掉后，会按项目名和工具类型尝试查找；找不到时提示“窗口已关闭或找不到”。
- **同窗限制**：Windows Terminal 多个标签等会话共用一个窗口时，只能把窗口拉到前面，不能切标签，浮窗会标“同窗”。Claude 桌面版可按旋钮 2 直接跳侧栏会话。其他 agent 建议一个会话开一个窗口。

### 让 agent 继续干、跑测试、总结
先切到那个会话，再按对应的键（M 继续、Ctrl+T 跑测试、Ctrl+D 总结，都在第 3 排；U 提交，在第 4 排第 3 颗）。

### 截图
按 L（第 3 排第 1 颗或旋钮 1 按下，同一信号）截全屏，保存到 `%USERPROFILE%\.agentdeck\shots\`。向所选会话粘贴：Claude / Codex 桌面版贴图片附件，终端、VS Code 等贴文件路径。

截图不自动回车。看到“截图已贴进输入框”后，补上问题，按旋钮 4 回车发送；Raw Input 读键时拒绝截图。

### 语音
默认用 Windows 自带听写 Win+H：按住 H（第 2 排第 3 颗）说话，松开结束。它会先把目标会话切到前台，再发送语音快捷键。

用 Typeless 等“点一下开始、再点一下结束”的工具时，在托盘“键位/语音快捷键”里录制它使用的键（例如**右 Alt**），并选“单点”。之后点一下 H 开始，再点一下 H 结束；松开 H 不会再发送快捷键。左 Alt 和右 Alt 是不同的键。

也可在 `%USERPROFILE%\.agentdeck\config.json` 中合并以下配置（165 是右 Alt）：

```json
{"dictation_shortcut": {"key_codes": [165], "modifiers": [], "mode": "tap"}}
```

“单点”不进入 AgentDeck 的“语音进行中”状态，不限制批准、切会话或滚动；用大键盘右 Alt 停止也可以。默认 Win+H 模式仍在按下、松开 H 时各点一次快捷键；“按住快捷键”模式仍按住、释放所选键。这两种模式语音进行中不能批准、切会话或滚动，松开 H 后再操作。

说完的话停在输入框里，看一眼没问题，按旋钮 4 回车发出去。Raw Input 读键时仍不能用语音。

### 翻看输出
转旋钮 3：一个方向往下、另一个方向往上（哪边往下以实际为准），一格滚 3 行左右；按下旋钮 3 直接回到底部。它会先把所选会话的窗口切到前台，再在窗口上发鼠标滚轮，鼠标会回到原位。窗口被浮窗等挡住时会换一个点，全被挡住就提示"窗口被挡住"。

### 回答 agent 的提问
Claude 用选择题问你（AskUserQuestion）或 MCP 要你填表时，会话变成"等你"，浮窗显示问题和选项。转旋钮 4 上下换选项，按下旋钮 4 提交。
为了安全：这个会话有待批命令（或 agent 自己弹出了权限确认）时，旋钮 4 一律不动，要用 ✓/✗ 处理，免得一个回车绕过"再按一次"和"锁定"；不在等你的时候，上下键也不动，免得翻出旧提问再被回车重发。

### 打断
按空格（第 1 排第 4 颗），相当于在那个会话里按 Esc。

## 浮窗
- AgentDeck 重启后会话列表和标题会保留（存在 `%USERPROFILE%\.agentdeck\sessions.json`）。超过 24 小时没有任何事件的会话会从列表和保存文件中清掉。
- 右上角 × 是隐藏，托盘左键单击可以再显示出来。
- 可以拖到任意位置，位置会记住。
- 浮窗不抢焦点，你在别的窗口打字不受影响。

## 托盘菜单（右键托盘图标）
- **显示 / 隐藏**：浮窗开关。
- **会话 / 下一个待批**：从菜单直接跳。
- **键位**：看键位图。
- **诊断**：检查钩子装好没有、键盘连上没有、读键方式是什么。出问题先看这里。
- **所有项目启用**：全局开关，勾上就是所有项目都接入。
- **单个项目**：只给某个文件夹装或卸。
- **开机自启**（写入任务计划程序）、**日志**、**退出**。

## AgentDeck 没开的时候
agent 照常在终端里问你，什么都不会坏。退出 AgentDeck 不需要做任何清理。

## 常见问题
- **按键时窗口里多出字母（g、e、空格），浮窗顶上有红字**：说明 AgentDeck 正在用 Raw Input 读键，这种方式拦不住按键。为了不把"m继续"这种东西发给 agent，这时旋钮 1 切窗口、发送预设、旋钮 4、语音、截图都会被拒绝，浮窗选会话、批准、滚动仍可用。要用 Zadig 把这把键盘的"接口 0"换成 WinUSB（步骤见 `装驱动.md`），之后按键只给 AgentDeck，不会漏到窗口。托盘"诊断"里显示"读键方式：USB 直读"就对了。我们自己做的设备不需要这一步。
- **按下去的功能和键帽上印的不一样**：键帽印的字不准，按上面"键位"一节的位置找键。
- **Codex 里按键没反应**：在 Codex 输入 `/hooks`，看 AgentDeck 的钩子有没有被信任。
- **浮窗没弹**：先看托盘图标在不在，再看"诊断"。已经开着的会话要重开一次。
- **键盘拔插后不认**：等 2 秒，会自动重连。
- **鼠标一直转圈**：那是 Windows 在别的程序启动时给的"忙"光标，不是 AgentDeck 引起的，过几秒会消失。
- **重启后没自动运行**：AgentDeck 用任务计划程序自启。打开"任务计划程序"，看根目录有没有叫 AgentDeck 的任务；没有就在托盘里重新打开"开机自启"。
- **Claude 出错停下**：会话变红点，浮窗写出错误原因。

## 卸载
托盘里取消"所有项目启用"，关掉"开机自启"（删掉任务计划程序里的 AgentDeck 任务），退出，再删掉 `dist\AgentDeck\` 文件夹。也可以运行 `AgentDeck.exe --uninstall`，效果一样。审计日志在 `%USERPROFILE%\.agentdeck\`，不想留可以一起删。
