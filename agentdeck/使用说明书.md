AgentDeck 使用说明书（CXT 宏键盘版，Windows）
版本：2026-11-19｜适用：`dist\AgentDeck\AgentDeck.exe`

## 它是什么
AgentDeck 是 Claude Code 和 Codex 的遥控器。agent 要你批准命令时，屏幕角落的浮窗会显示那条命令，你在宏键盘上按 ✓ 或 ✗ 就行，不用切窗口找按钮。同时开好几个 agent 时，浮窗能看出谁在跑、谁在等你，按一颗键就能跳过去。

它不替代键鼠：写长需求、看 diff、选中文字问 agent，还是用键鼠。键盘上没有屏幕，命令内容要看电脑上的浮窗。

## 第一次使用（约 1 分钟）
1. 把整个 `dist\AgentDeck\` 文件夹放在固定位置，以后别挪。挪了也没关系，下次启动会自动修好路径。
2. 双击 `AgentDeck.exe`，在弹出的窗口里点"开始使用"。它会做三件事：
   - 让所有项目的 Claude Code 和 Codex 都接入；
   - 换掉旧版 1602 钩子；
   - 设置开机自启。
3. 如果你用 Codex：在 Codex 里输入 `/hooks`，选信任。只需要一次，这是 Codex 的安全规定。Claude 不用做这步。
4. 已经开着的 agent 会话要重开一次，新开的会话自动生效。

之后每次开机都会自动运行，任务栏右下角托盘里有个小图标。

## 键位
宏键盘有 4 列 5 排共 20 颗键，加 4 个旋钮。键盘上印的字母就是它实际发出的键。

| 位置 | 键盘发出的键 | 功能 |
|---|---|---|
| 第 1 排第 1 颗 | E | 跳到会话 1 |
| 第 1 排第 2 颗 | B | 跳到会话 2 |
| 第 1 排第 3 颗 | Ctrl+Z | 跳到会话 3 |
| 第 1 排第 4 颗 | 空格 | 打断当前会话（相当于按 Esc） |
| 第 2 排第 1 颗 | G | ✓ 批准 |
| 第 2 排第 2 颗 | Ctrl+F | ✗ 拒绝 |
| 第 2 排第 3 颗 | H（按住） | 语音输入：按住说话，松开结束 |
| 第 3 排第 1 颗 | L | 截图 |
| 第 3 排第 2 颗 | M | 发送"继续" |
| 第 3 排第 3 颗 | Ctrl+T | 发送"跑测试" |
| 第 3 排第 4 颗 | Ctrl+D | 发送"总结进度" |
| 第 4 排第 1 颗 | U | 发送"提交" |
| 第 4 排第 2 颗 | X | 下一个会话 |
| 第 5 排第 1 颗 | Tab | 跳到下一个在等你的会话 |
| 第 5 排第 2 颗 | P | 上一个会话 |
| 4 个旋钮转动 | — | 在会话之间前后切换 |
| 旋钮 1 按下 | L | 截图 |
| 旋钮 2 按下 | Q | 发送"跑测试" |
| 旋钮 3 按下 | V | 发送"总结进度" |
| 旋钮 4 按下 | Ctrl+0 | 发送"继续" |

托盘右键选"键位"，能看到这张图。

"发送'继续'"这类键，会把一句写好的话粘贴进当前会话再回车。这些话在 `%USERPROFILE%\.agentdeck\hub_prompts.json` 里，可以改。

## 日常怎么用

### 批准命令
1. agent 要执行需要批准的命令时，浮窗会弹出来：上面是会话列表，下面是那条命令。
2. 看清命令，按 G（✓）放行，或按 Ctrl+F（✗）拒绝。
3. 危险命令（强推、删目录等）浮窗会标红并提示"再按一次"，1.5 秒内再按一次 ✓ 才放行。
4. 最危险的一类会直接锁住，键盘批准不了，要回终端处理。这是故意的。
5. 防误触：命令刚出现的 0.3 秒内按键不算数，免得你按到上一条去。

### 看谁在等你
浮窗每行是一个会话，左边的点表示状态：

| 颜色 | 状态 |
|---|---|
| 绿 | 在跑 |
| 琥珀 | 等你批准或回复 |
| 蓝 | 做完了，等你验收 |
| 红 | 出错 |
| 灰 | 空闲 |

按 Tab 跳到下一个等你的会话。

### 切换会话
- 会话 1–3 直接按 E / B / Ctrl+Z。更多的会话用旋钮或 X / P 前后切。
- 切换的原理：AgentDeck 记得每个会话在哪个项目文件夹。按键后，它会找标题里带这个项目名的终端或窗口，把它切到最前面。所以同一个项目只开一个窗口最好认。找不到窗口时，浮窗会提示原因。

### 让 agent 继续干、跑测试、总结
先切到那个会话，再按对应的键（M 继续、Ctrl+T 跑测试、Ctrl+D 总结、U 提交）。

### 语音
按住 H 说话，松开结束。它会先把目标会话切到前台，再打开语音输入。目前用的是 Windows 自带听写（Win+H），后面会支持改成 Typeless 的快捷键。语音进行中不能批准，免得说话时误按。

### 打断
按空格，相当于在那个会话里按 Esc。

## 浮窗
- 右上角 × 是隐藏，托盘左键单击可以再显示出来。
- 可以拖到任意位置，位置会记住。
- 浮窗不抢焦点，你在别的窗口打字不受影响。

## 托盘菜单（右键托盘图标）
- **显示 / 隐藏**：浮窗开关。
- **会话 / 下一个待批**：从菜单直接跳。
- **键位**：看键位图。
- **诊断**：检查钩子装好没有、键盘连上没有、读键方式是什么。出问题先看这里。
- **所有项目启用**：全局开关，勾上就是所有项目都接入。
- **单个项目**：只给某个文件夹装或卸。
- **开机自启**、**日志**、**退出**。

## AgentDeck 没开的时候
agent 照常在终端里问你，什么都不会坏。退出 AgentDeck 不需要做任何清理。

## 常见问题
- **按键时窗口里多出字母（g、e、空格）**：说明 AgentDeck 正在用 Raw Input 读键，这种方式拦不住按键。要用 Zadig 把这把键盘的"接口 0"换成 WinUSB，之后按键只给 AgentDeck，不会漏到窗口。托盘"诊断"里显示"读键方式：USB 直读"就对了。我们自己做的设备不需要这一步。
- **Codex 里按键没反应**：在 Codex 输入 `/hooks`，看 AgentDeck 的钩子有没有被信任。
- **浮窗没弹**：先看托盘图标在不在，再看"诊断"。已经开着的会话要重开一次。
- **键盘拔插后不认**：等 2 秒，会自动重连。

## 卸载
托盘里取消"所有项目启用"，关掉"开机自启"，退出，再删掉 `dist\AgentDeck\` 文件夹。也可以运行 `AgentDeck.exe --uninstall`，效果一样。审计日志在 `%USERPROFILE%\.agentdeck\`，不想留可以一起删。
