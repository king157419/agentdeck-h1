AgentDeck 使用说明书（CXT 宏键盘版，Windows）
版本：2026-11-19｜适用：`dist\AgentDeck\AgentDeck.exe`

## 它是什么
AgentDeck 是 Claude Code 和 Codex 的遥控器。agent 要你批准命令时，屏幕角落的浮窗会显示那条命令，你在宏键盘上按 ✓ 或 ✗ 就行，不用切窗口找按钮。同时开好几个 agent 时，浮窗能看出谁在跑、谁在等你，还显示每个会话最新的一句话；按一颗键就能跳过去，转旋钮就能翻看它的输出、回答它的提问。

它不替代键鼠：写长需求、看 diff、选中文字问 agent，还是用键鼠。键盘上没有屏幕，命令内容要看电脑上的浮窗。

## 第一次使用（约 1 分钟）
1. 把整个 `dist\AgentDeck\` 文件夹放在固定位置，以后别挪。挪了也没关系，下次启动会自动修好路径。
2. 双击 `AgentDeck.exe`，在弹出的窗口里点"开始使用"。它会做三件事：
   - 让所有项目的 Claude Code 和 Codex 都接入；
   - 换掉旧版 1602 钩子；
   - 设置开机自启。
3. 如果你用 Codex：在 Codex 里输入 `/hooks`，选信任。只需要一次，这是 Codex 的安全规定。Claude 不用做这步。
4. 已经开着的 agent 会话要重开一次，新开的会话自动生效。

之后每次开机都会自动运行，任务栏右下角托盘里有个小图标。

## 键位
宏键盘有 4 列 5 排共 20 颗键，加 4 个旋钮。键盘上印的字母就是它实际发出的键。

| 位置 | 键盘发出的键 | 功能 |
|---|---|---|
| 第 1 排第 1 颗 | E | 跳到会话 1 |
| 第 1 排第 2 颗 | B | 跳到会话 2 |
| 第 1 排第 3 颗 | Ctrl+Z | 跳到会话 3 |
| 第 1 排第 4 颗 | 空格 | 打断当前会话（相当于按 Esc） |
| 第 2 排第 1 颗 | G | ✓ 批准 |
| 第 2 排第 2 颗 | Ctrl+F | ✗ 拒绝 |
| 第 2 排第 3 颗 | H（按住） | 语音输入：按住说话，松开结束 |
| 第 3 排第 1 颗 | L | 截图 |
| 第 3 排第 2 颗 | M | 发送"继续" |
| 第 3 排第 3 颗 | Ctrl+T | 发送"跑测试" |
| 第 3 排第 4 颗 | Ctrl+D | 发送"总结进度"（⚠ 危险键：没装 WinUSB 时会漏进窗口，连按两次退出 Claude Code） |
| 第 4 排第 1 颗 | U | 发送"提交" |
| 第 4 排第 2 颗 | X | 下一个会话 |
| 第 5 排第 1 颗 | Tab | 跳到下一个在等你的会话 |
| 第 5 排第 2 颗 | Ctrl+C | 不绑定（⚠ 危险键：漏进窗口会打断 agent，连按会退出） |
| 第 5 排第 3 颗 | Ctrl+V | 不绑定（⚠ 危险键：漏进窗口会粘贴剪贴板） |
| 第 5 排第 4 颗 | P | 上一个会话 |
| 旋钮 1、2 转动 | S/F、R/P | 在会话之间前后切换 |
| 旋钮 1 按下 | L | 截图 |
| 旋钮 2 按下 | Q | 显示浮窗（隐藏后叫回来） |
| 旋钮 3 转动 | - / = | 滚动所选会话的窗口：顺时针往下看新内容，逆时针往上翻 |
| 旋钮 3 按下 | V | 直接滚到底 |
| 旋钮 4 转动 | ] / [ | 下 / 上方向键：agent 提问时换选项 |
| 旋钮 4 按下 | Ctrl+0 | 回车：提交选项，或把语音说完的话发出去 |

托盘右键选"键位"，能看到这张图。

"发送'继续'"这类键，会把一句写好的话粘贴进当前会话再回车。这些话在 `%USERPROFILE%\.agentdeck\hub_prompts.json` 里，可以改。

## 日常怎么用

### 批准命令
1. agent 要执行需要批准的命令时，浮窗会弹出来：上面是会话列表，下面是那条命令。
2. 看清命令，按 G（✓）放行，或按 Ctrl+F（✗）拒绝。
3. 危险命令（强推、删目录等）浮窗会标红并提示"再按一次"，1.5 秒内再按一次 ✓ 才放行。
4. 最危险的一类会直接锁住，键盘批准不了，要回终端处理。这是故意的。
5. 防误触：命令刚出现的 0.3 秒内按键不算数，免得你按到上一条去。

### 看谁在等你、它说了什么
浮窗每行是一个会话。等你的会话名字变成琥珀色，后面写着"等你"；正在跑的会话，名字后面用灰字写它在用什么工具。

会话列表下面是一块"最新一句话"：所选会话（没选就是第一个等你的会话）最后说的话、你最后发的话或它的提问，最多 8 行，标题写着第几号、哪种消息、多久之前。浮窗在显示这个会话的待批命令时，先显示命令。

右边的点表示状态：

| 颜色 | 状态 |
|---|---|
| 绿 | 在跑 |
| 琥珀 | 等你批准或回复 |
| 蓝 | 做完了，等你验收 |
| 红 | 出错 |
| 灰 | 空闲 |

按 Tab 跳到下一个等你的会话。

### 切换会话
- 会话 1–3 直接按 E / B / Ctrl+Z。更多的会话用旋钮或 X / P 前后切。
- 切换的原理：每次钩子运行时，AgentDeck 记下这个 agent 所在的那个窗口（终端、VS Code、Claude 或 Codex 桌面版），按键直接切过去，不管窗口标题写的是什么。这个窗口关掉了，才退回按"标题里带项目名"去找。两条路都找不到时，浮窗提示"窗口已关闭或找不到"。
- 限制：同一个窗口里开了多个会话（Windows Terminal 多个标签、桌面版里多个对话）时，只能把窗口拉到前面，切不了标签，浮窗会在这些会话后面标"同窗"。建议一个 agent 开一个窗口。

### 让 agent 继续干、跑测试、总结
先切到那个会话，再按对应的键（M 继续、Ctrl+T 跑测试、Ctrl+D 总结、U 提交）。

### 语音
按住 H 说话，松开结束。它会先把目标会话切到前台，再打开语音输入（默认是 Windows 自带听写 Win+H，托盘"键位"里可以改成 Typeless 等的快捷键）。说完的话停在输入框里，看一眼没问题，按旋钮 4 回车发出去。语音进行中不能批准、切会话或滚动，免得说话时误按。

### 翻看输出
转旋钮 3：顺时针往下、逆时针往上，一格滚 3 行左右；按下旋钮 3 直接回到底部。它会先把所选会话的窗口切到前台，再在窗口上发鼠标滚轮，鼠标会回到原位。窗口被浮窗等挡住时会换一个点，全被挡住就提示"窗口被挡住"。

### 回答 agent 的提问
Claude 用选择题问你（AskUserQuestion）或 MCP 要你填表时，会话变成"等你"，浮窗显示问题和选项。转旋钮 4 上下换选项，按下旋钮 4 提交。
为了安全：这个会话有待批命令（或 agent 自己弹出了权限确认）时，旋钮 4 一律不动，要用 ✓/✗ 处理，免得一个回车绕过"再按一次"和"锁定"；不在等你的时候，上下键也不动，免得翻出旧提问再被回车重发。

### 打断
按空格，相当于在那个会话里按 Esc。

## 浮窗
- 右上角 × 是隐藏，托盘左键单击可以再显示出来。
- 可以拖到任意位置，位置会记住。
- 浮窗不抢焦点，你在别的窗口打字不受影响。

## 托盘菜单（右键托盘图标）
- **显示 / 隐藏**：浮窗开关。
- **会话 / 下一个待批**：从菜单直接跳。
- **键位**：看键位图。
- **诊断**：检查钩子装好没有、键盘连上没有、读键方式是什么。出问题先看这里。
- **所有项目启用**：全局开关，勾上就是所有项目都接入。
- **单个项目**：只给某个文件夹装或卸。
- **开机自启**、**日志**、**退出**。

## AgentDeck 没开的时候
agent 照常在终端里问你，什么都不会坏。退出 AgentDeck 不需要做任何清理。

## 常见问题
- **按键时窗口里多出字母（g、e、空格），浮窗顶上有红字**：说明 AgentDeck 正在用 Raw Input 读键，这种方式拦不住按键。为了不把"m继续"这种东西发给 agent，这时发送预设、旋钮 4、语音、截图都会被拒绝，只能切会话、批准、滚动。要用 Zadig 把这把键盘的"接口 0"换成 WinUSB（步骤见 `装驱动.md`），之后按键只给 AgentDeck，不会漏到窗口。托盘"诊断"里显示"读键方式：USB 直读"就对了。我们自己做的设备不需要这一步。
- **Codex 里按键没反应**：在 Codex 输入 `/hooks`，看 AgentDeck 的钩子有没有被信任。
- **浮窗没弹**：先看托盘图标在不在，再看"诊断"。已经开着的会话要重开一次。
- **键盘拔插后不认**：等 2 秒，会自动重连。

## 卸载
托盘里取消"所有项目启用"，关掉"开机自启"，退出，再删掉 `dist\AgentDeck\` 文件夹。也可以运行 `AgentDeck.exe --uninstall`，效果一样。审计日志在 `%USERPROFILE%\.agentdeck\`，不想留可以一起删。
