# AgentDeck 使用说明书

CXT 宏键盘版，Windows｜键位 v9｜2026-11-20

本说明对应 v9 源码。本次没有重新打包 exe，已有 `dist\AgentDeck\AgentDeck.exe` 不会因说明书更新而自动变成 v9。键位变更以新版程序实际加载的 `hub_keys.json` 为准。

## 它是什么

AgentDeck 是 Claude Code 和 Codex 的遥控器。agent 要你批准命令时，电脑上的浮窗显示命令，你在宏键盘上按批准或拒绝。多个会话同时运行时，浮窗显示谁在跑、谁在等你；旋钮可以选会话、切窗口、滚动当前栏和选择当前应用里的项目。

宏键盘没连接时，AgentDeck 不扣住批准请求，回到 agent 自己的确认流程。键盘没有屏幕，批准前请看电脑上的命令卡片。写长需求、读 diff、选中文字等仍用键鼠。

## 第一次使用

以下为已有桌面程序的安装流程；使用 v9 键位须先运行包含 v9 改动的版本。

1. 把整个 `dist\AgentDeck\` 文件夹放在固定位置，双击 `AgentDeck.exe`。
2. 首次点“开始使用”，程序会接入所有项目的 Claude Code 和 Codex、替换旧版 1602 钩子，并设置登录时自动启动。
3. Codex 用户在 Codex 中输入 `/hooks` 并信任钩子，只需一次。Claude 不需要这步。
4. 已经打开的 agent 会话需要重开，新会话自动生效。

再次启动不会开第二个进程，而是打开状态窗口。Windows 11 的托盘图标可能藏在右下角时钟旁的 `^` 中，可拖到任务栏上。

状态窗口的“宏键盘”一行显示是否连接，以及 USB 直读 / Raw Input 等读键方式。v9 完整键位使用 **USB 直读**；Raw Input 无法阻止原按键漏进窗口，部分输入动作会被拒绝。

## 键位 v9：按物理位置找键

宏键盘有 4 列、5 排、4 个旋钮。排从上往下数，列从左往右数；**第 5 排最靠近手**。旋钮从左往右是 1 到 4。键帽印字不一定等于实际信号，以下按实测位置说明。

只有第 2 排和旋钮 4 随前台应用变。其余位置固定。

| 位置 | 实际信号 | 功能 |
|---|---|---|
| 第 1 排第 1 颗 | E | Claude / Codex 桌面窗口 |
| 第 1 排第 2 颗 | B | 微信窗口 |
| 第 1 排第 3 颗 | Ctrl+Z | 飞书窗口 |
| 第 1 排第 4 颗 | 空格 | 浏览器窗口 |
| 第 2 排第 1 颗 | G | 当前层动作 1 |
| 第 2 排第 2 颗 | Ctrl+F | 当前层动作 2 |
| 第 2 排第 3 颗 | H | 当前层动作 3 |
| 第 2 排第 4 颗 | 单独 Alt | 当前层动作 4 |
| 第 3 排第 1 颗 | L | 上一个窗口 / 确认切换，与旋钮 1 按下相同 |
| 第 3 排第 2 颗 | M | 复制，Ctrl+C |
| 第 3 排第 3 颗 | Ctrl+T | 粘贴，Ctrl+V |
| 第 3 排第 4 颗 | Ctrl+D | 点按开关浮窗；按住显示帮助；按住转旋钮移动浮窗 |
| 第 4 排第 1 颗 | 单独 Ctrl | Agent 层打断；其他层 Esc；切窗口时取消切换 |
| 第 4 排第 2 颗 | 单独 Shift | 截图，沿用原有截图流程 |
| 第 4 排第 3 颗 | U | 发送；Agent 层先检查输入框，其他层 Enter |
| 第 4 排第 4 颗 | X | 清空当前可编辑输入框 |
| 第 5 排第 1 颗 | Tab | 批准浮窗当前显示的请求 |
| 第 5 排第 2 颗 | Ctrl+C | 拒绝浮窗当前显示的请求 |
| 第 5 排第 3 颗 | Ctrl+V | 语音，沿用已配置的快捷键与按住 / 单点模式 |
| 第 5 排第 4 颗 | P | 留空；与旋钮 2 逆时针同码，单按不够一个软件步长 |

### 三颗只发修饰键的键

第 2 排第 4 颗 Alt、第 4 排第 1 颗 Ctrl、第 4 排第 2 颗 Shift，只在 USB 直读下响应。**单独按下，在 600 毫秒内松开，松开时才执行。** 按住不放不会触发；期间按过其他键，或组成 Ctrl+Z 等组合键，也不会触发单按动作。Raw Input 下这三颗不触发。

### 第 1 排：应用直达

按下把对应应用调到前台；该应用已经在前台时再按，回上一个窗口。Claude 和 Codex 桌面版都打开时，第 1 颗在两者之间切换。浏览器键选择最近使用过的 Chrome、Edge 或 Firefox 窗口。

没有找到对应窗口时显示红字，例如“没找到微信窗口”，不会误向其他应用输入。微信收到托盘时，程序可尝试一次它的唤起快捷键。

### 自动层与第 2 排

前台应用稳定 300 毫秒后自动切层，不需要手动切。切层时显示层名 1 秒。Alt+Tab 切换中，或会话 / 列表卡片开着时，暂不切层。

| 层 | 适用前台应用 |
|---|---|
| Agent | Claude、Codex 桌面版 |
| 聊天 | 微信、飞书 |
| 浏览器 | Chrome、Edge、Firefox |
| 视频 | 浏览器标题含哔哩哔哩、抖音或 YouTube，或浏览器全屏 |
| 默认 | 其他应用 |

第 2 排从左往右的功能如下：

| 层 | 第 1 颗 | 第 2 颗 | 第 3 颗 | 第 4 颗 |
|---|---|---|---|---|
| Agent | 发“继续” | 发“跑测试” | 发“总结” | 到最新 |
| Agent 提问中 | 选项 1 | 选项 2 | 选项 3 | 选项 4 |
| 聊天 | 暂未实现：下个未读 | 找人 | 填入“收到” | 到最新 |
| 浏览器 | 后退 | 地址栏 | 关标签 | 刷新 |
| 视频 | 播放 / 暂停 | 上一条 | 下一条 | 全屏 |
| 默认 | 后退 | Tab | Ctrl+W | 到底 |

Agent 模板只在**输入框为空、当前会话没有待批请求**时发送，避免覆盖草稿或用回车绕过批准。否则灰字说明原因，不发送任何按键。模板文字可在 `hub_prompts.json` 中配置。

聊天“找人”在微信使用 Ctrl+F，飞书使用 Ctrl+K；“收到”只粘贴，不自动回车。聊天“下个未读”和切聊天本步未做，按下显示灰字“这一步还没做”。

浏览器后退 / 地址栏 / 关标签 / 刷新分别是 Alt+Left、Ctrl+L、Ctrl+W、F5。视频第 2、3 颗是上 / 下方向键，第 4 颗是 F。默认层“到底”是 Ctrl+End。Agent“到最新”针对当前 Claude 对话栏。

### 旋钮 1：窗口

顺时针发 F，逆时针发 S，按下发 L。

- 第一步不分方向，都先按住 Alt 并点 Tab，到上一个窗口。
- 继续顺时针前进，逆时针后退；到头后夹住，不无限绕圈。
- 按下旋钮，或按第 3 排第 1 颗：切换中立即确认；没有切换时回上一个窗口。
- 停转 **700 毫秒**自动确认，可用 `window_switch_release_ms` 调整。
- 切换中单按第 4 排第 1 颗 Ctrl：Esc 取消，再松开 Alt。执行其他功能前会先松开 Alt；连续切换超过 5 秒也强制松开。

### 旋钮 2：会话卡片

顺时针发 R，逆时针发 P，按下发 Q。

转动只打开并移动 AgentDeck 会话卡片的高亮，**不会切换或激活任何目标窗口**。最多显示 7 行，标题最多 18 字；依次排等批准、正在提问、出错、完成未读、运行中、空闲，同类按最近活动排序。卡片打开期间顺序冻结。

刚打开时先从列表首项开始，后台读取 Claude 当前会话后对齐起点。按下才跳到选中的会话；Claude 会激活窗口、调用侧栏会话并确认。选中行先显示“正在打开…”，确认后才报成功；2 秒未成功重试一次，仍失败显示红字。

卡片没开时按下，跳到下一个等你的会话；没有则灰字“没有等你的会话”。转动后 **2.5 秒**未按下，卡片收起，不执行操作。第 5 排第 4 颗与逆时针同码，单按只有一个脉冲，因此留空。

### 旋钮 3：当前窗口选栏与滚动

顺时针发 `-`，逆时针发 `=`，按下发 V。

转动滚动**当前前台窗口**所选的栏；不会先把其他会话调到前台。程序把鼠标移到目标栏右边缘内侧约 16 像素、垂直中间，再发送顺滑滚轮；**鼠标会留在那里**。密集转动会加速，停手后短暂减速收尾。

按下切到下一栏，各栏出现“左 / 中 / 右 + 序号”的框线，当前栏加粗，1.2 秒后消失。每个应用记住上次选中的栏，Claude 默认对话中栏。栏位在后台读取，先使用缓存；没有识别到可滚栏时，使用整个窗口中间。

### 旋钮 4：当前层列表

顺时针发 `]`，逆时针发 `[`，按下发 C。

| 层 | 转动 | 按下 |
|---|---|---|
| Agent 提问中 | 在问题选项间选择 | 回车（列表开着时确认选项） |
| Agent 其他时候 | 在提示模板中选择 | 回车（列表开着时检查条件并发送模板） |
| 聊天 | 暂未实现切聊天 | 回车 |
| 浏览器 | 选前 / 后标签页 | 回车（列表开着时确认切换） |
| 视频 | 选后退 / 前进 5 秒 | 确认；无选择时播放 / 暂停 |
| 默认 | 选上 / 下方向 | 确认；无选择时回车 |

旋钮 4 按下：**回车（列表开着时确认）**。没有打开列表时，Agent、聊天、浏览器和默认层直接向当前前台窗口发送一次普通回车，可用于问题选项或确认框；视频层仍为播放 / 暂停。转动后的选择先显示在列表卡片，按下才执行。浏览器标签页快捷键为 Ctrl+PgUp / Ctrl+PgDn；视频快退 / 快进使用左 / 右方向键。提问或模板遇到待批请求时，先用批准 / 拒绝处理。

### 旋钮手感设置

旋钮 1、2、4 用软件步长减少误跳：停手后先累计 2 个同向脉冲才出第一步，后续默认旋钮 1 每 4 个脉冲一步，旋钮 2、4 每 3 个一步。单个反向脉冲会忽略，100 毫秒内连续两个反向才换向。静止 250 毫秒后清零，两步之间至少间隔 90 毫秒，多出来的步数直接丢弃。

旋钮 3 只做方向去抖，不受步长分格影响。可以在 `%USERPROFILE%\.agentdeck\config.json` 中调整：

```json
{
  "knob_divider": {"1": 4, "2": 3, "4": 3},
  "window_switch_release_ms": 700
}
```

没有配置到的旋钮采用上述默认值。管理面板显示并修改当前键位；未修改的 v8 默认文件升级时备份为 `hub_keys.json.bak-v8`，自己改过的绑定保留。绑定支持按层覆盖，先找当前层，再找全局。

## 浮窗和反馈

单屏默认在屏幕右侧中间显示 **28 像素宽的竖条**，最多 6 个会话，每个 22 像素高，用色点加“批、问、完、错、跑、闲”表示状态。双屏默认在副屏右上角显示会话卡片列表。浮窗鼠标穿透、不抢输入焦点。

| 标记 | 意思 |
|---|---|
| 批 | 等批准 |
| 问 | agent 在提问 |
| 完 | 完成、等待查看 |
| 错 | 出错 |
| 跑 | 运行中 |
| 闲 | 空闲 |

卡片宽 320 到 360 像素，只在有批准请求、agent 提问、转旋钮 2 / 4、按住帮助时展开。批准卡片展示会话标题、工具名、命令首行（最多 60 字），多条请求显示 `1/3` 等序号。

### 开关、帮助、移动

第 3 排第 4 颗 Ctrl+D：

- 点按：显示 / 隐藏竖条。隐藏时新的批准请求仍会弹卡片 3 秒。
- 按住超过 400 毫秒：显示当前层键位图，松开消失。
- 按住时转任意旋钮：在右中、右上、右下、左中、左上、左下六个停靠点和各块屏幕间循环，松手保存位置。

### 三种结果

结果显示在竖条旁边独立的 **220 × 28 像素**小条中，0.9 秒后消失。主浮窗不移动、不变大。

| 颜色 | 意思 | 示例 |
|---|---|---|
| 绿 | 做了 | 已批准：npm test（修登录）；已发送：继续 |
| 灰 | 没东西可做 | 输入框是空的；没有等你的会话；这里不是输入框 |
| 红 | 没做成 | 没找到微信窗口；会话打开失败 |

**灰字表示未执行，不向任何应用发送按键，也不为这次无效操作展开卡片。** 同一无效操作 3 秒内不重复弹。操作超过 0.5 秒先显示“正在…”，结束后显示结果。滚动、切窗口、粘贴不出提示。

## 日常操作

### 批准与拒绝

宏键盘连接时，AgentDeck 扣住批准请求，卡片显示命令。看清后按**第 5 排第 1 颗 Tab 批准**，或**第 5 排第 2 颗 Ctrl+C 拒绝**。

卡片刚出现的 **400 毫秒**内批准 / 拒绝无效，防止误按上一条。危险命令仍按原有规则提示“再按一次”，需在 1.5 秒内再次批准；最高风险命令仍须回应用处理。

没有待批请求时只显示灰字“现在没有要批准的请求”。没插键盘时不拦批准，按应用自己的确认流程处理。

### 发送、打断、清空

- **发送：第 4 排第 3 颗 U。** Agent 层先读 Claude 输入框，空白则提示“输入框是空的”；有内容才聚焦并发送。其他层发送 Enter。
- **打断：第 4 排第 1 颗单独 Ctrl。** Agent 层调用 Claude 的 Stop 按钮，没有按钮则提示“没有在跑的任务”；其他层发送 Esc。Alt+Tab 切换中优先取消切换。
- **清空：第 4 排第 4 颗 X。** 只有当前焦点是可编辑文本框才发送 Ctrl+A、Delete；否则提示“这里不是输入框”。
- **复制 / 粘贴：第 3 排第 2 / 3 颗。** 分别发送 Ctrl+C / Ctrl+V，粘贴不自动回车。

Agent 层的输入框 / Stop 操作依赖 Claude 界面元素。识别不到时显示未执行或失败，不能用误发到其他位置的回车替代。Codex 桌面窗口也归 Agent 层，但 Claude 专用界面操作的可用性以实际识别结果为准。

### 语音

语音移到**第 5 排第 3 颗 Ctrl+V**，沿用已有语音快捷键和模式。默认 Win+H 模式按下开始、松开结束；已有“按住快捷键”模式保持对应按下 / 松开行为。

Typeless 等工具可在浮窗右键菜单“键位”窗口的“语音快捷键”中选择“单点”：点一下发送一次快捷键开始，再点一下结束，松开按键不补发。右 Alt 的配置示例：

```json
{"dictation_shortcut": {"key_codes": [165], "modifiers": [], "mode": "tap"}}
```

单点模式不锁住其他操作；需要 AgentDeck 维持目标的已有语音模式，在结束前仍限制批准、切会话和滚动。Raw Input 不启用语音。v9 本步没有新增自动聚焦输入框或新的按住说话流程。

说完先检查输入内容，再按第 4 排第 3 颗发送。旋钮 4 按下为回车（列表开着时确认），视频层无列表时为播放 / 暂停。

### 截图

截图移到**第 4 排第 2 颗单独 Shift**，沿用原有行为：保存到 `%USERPROFILE%\.agentdeck\shots\`，按原流程向目标粘贴图片或文件路径，不自动回车。Raw Input 下该单修饰键不触发。

v9 本步没有新增截图自动贴到 Claude 的工作流。旋钮 1 按下已改为窗口确认 / 上一个窗口，不再截图。

## 会话、托盘与保存

会话标题与列表仍保存在 `%USERPROFILE%\.agentdeck\sessions.json`，重新启动后恢复；超过 24 小时没有事件的会话会清理。Claude 会话能读取侧栏标题时显示标题，否则回退到项目名。

托盘菜单第一项是“管理面板”（双击托盘图标也一样），其余是显示 / 隐藏浮窗、会话、诊断、项目接入设置、开机自启、日志和退出。旧的“状态”“键位”窗口不再从菜单进入。

## 管理面板

托盘点“管理面板”，会用 Edge 的应用模式开一个独立窗口（找不到 Edge 就用默认浏览器）；同一时间只开一个，再点一次是把它调到前台。面板是 AgentDeck 自己提供的本地网页，只在本机 127.0.0.1 上，不联网。每次打开用一次性登录码（60 秒有效、只能用一次），登录后窗口里的地址是干净的。窗口提示“需要重新登录”时，从托盘再点一次“管理面板”。

- **顶栏：** 宏键盘是否连着、读键方式（“USB 直读”才是完整功能）；“拦截批准”选自动 / 总是 / 从不，作用和以前一样。
- **左栏“最近活动”：** 每个会话一行，显示标题、Claude 或 Codex、项目、状态和多久以前。Claude 里正打开的那个会标“Claude 里正打开”。点一行就跳到这个会话。等批准的会话下面有命令首行和“批准”“拒绝”两个按钮，只对这一条请求生效；高危请求要再点一次批准。
- **右侧键盘图：** 4 个旋钮加 5×4 颗键，每颗写着当前的功能。上方一排按钮看某一层的键位（Agent、聊天、浏览器、视频、默认），只影响图上显示和修改，不会切换真实的层；真实的层旁有绿点。按下实体键，图上对应的键亮约 0.6 秒，下方显示这次的结果。
- **改键：** 点一颗键，右边列出可选功能，选中即保存、立即生效，“恢复默认”回到出厂。第 1 排可改成 Claude / Codex、微信、飞书、浏览器或一个自己指定的程序（填 exe 完整路径，按文件名找它已经开着的窗口，不会替你启动它）；第 2 排和旋钮 4 按所选的层分别改，可选提示模板、复制 / 粘贴 / 发送等快捷键动作或“空”。第 3–5 排、旋钮 1–3 是固定键，面板里显示锁，不能改。带蓝点的键是你改过的。
- **保存在哪：** 改动写进 `%USERPROFILE%\.agentdeck\hub_keys.json` 并标记为“用户改过”，以后升级 AgentDeck 不会覆盖。想全部回到出厂，删掉这个文件再重启即可。

AgentDeck 没运行时，agent 照常在自己的界面请求确认。退出程序会释放它持有的切窗口和语音快捷键。

## 常见问题

- **所有键都失灵：** 先检查系统托盘（包括右下角的 ^）里有没有 AgentDeck 图标。若 AgentDeck 意外退出，新版会在下一次 Claude 或 Codex 触发钩子时尝试自动启动。
- **功能和键帽印字不同：** 按“第几排第几颗”和旋钮编号找键，v9 的批准 / 拒绝已经移到最靠近手的第 5 排。
- **窗口出现原始字母或快捷键：** 当前可能是 Raw Input，无法隔离这把键盘。通过 Zadig 把 `4132:2107` 的接口 0 改为 WinUSB，具体步骤见 `装驱动.md`；仅修改接口 0。诊断显示“USB 直读”后再使用完整键位。
- **单按 Alt / Ctrl / Shift 没反应：** 检查 USB 直读；必须单独按并在 600 毫秒内松开。组合键和长按不会触发。
- **聊天未读 / 切聊天灰字：** 本步未做，显示“这一步还没做”是预期行为。
- **模板不发送：** 先清理输入框草稿，并处理当前待批请求。灰字会说明未执行原因。
- **旋钮转一格没响应：** 这是软件步长，不是每个原始脉冲都执行；可按手感调整 `knob_divider`。
- **鼠标滚动后没有回原处：** v9 会把鼠标留在目标栏，便于确认滚的是哪里。按旋钮 3 换栏。
- **Codex 钩子没有反应：** 在 Codex 输入 `/hooks`，确认已信任 AgentDeck。已有会话需重开。
- **键盘拔插后没立即认出：** 等约 2 秒，程序自动重连。
- **重启后没有运行：** 在 Windows 任务计划程序中检查 AgentDeck 登录任务，或通过托盘重新启用开机自启。

## 本步边界与实机确认

本步不新增点选标签、语音自动聚焦 / 新按住说话流程、截图一键贴流程、微信 / 飞书切聊天和下个未读。既有语音与截图功能保留。

离线测试只能验证逻辑。Claude 栏位识别、滚动手感、窗口和会话切换准确率还需实机确认；建议各做 20 次“切到第 3 个窗口”和“选第 4 个会话”，检查错误是否少于 2 次。说明书更新不代表这轮实机验收已经完成。

## 卸载

在托盘取消“所有项目启用”、关闭“开机自启”，退出后删除程序目录；也可运行 `AgentDeck.exe --uninstall`。日志和审计文件保存在 `%USERPROFILE%\.agentdeck\`，需要时自行保留或清理。
