## 软件原型（`pc/`）

- Hub v1.1–v1.4：本地中枢 + 钩子转发 + 一键安装器。功能包括：批准 / 拒绝、高危命令按两次、极危命令锁死、哈希链审计日志、`doctor` 自检（v1.1）、按住说话时守住目标窗口（v1.2）、F13–F24 全局热键 + 置顶 6 槽小浮窗（v1.3）、`PreToolUse` 高危闸门（v1.4，两次 ✓ 返回 `{}`，agent 规则照常生效；✗ 或超时 deny；`install --gate`）。另有演示模式 `pc/hub_demo.py`（已用真实热键 4 倍速跑通）与虚拟 v2 设备窗口 `pc/hub_virtual_device.py`（由真实 hub 驱动），以及微雪 3.49 寸长条屏固件草稿 `firmware/strip349/`（协议解析已过 C++ 单测，整板未编译烧录【待实测】）。闸门用真实进程和真实系统热键（F19/F20）验证，真实 auto mode 会话待测。离线测试：中枢 264 项单元测试（`test_hub*.py`，含演示模式与虚拟设备）+ 回放自检 12/12，全部通过。
- 还没做：高危闸门在真实 auto mode 的 Claude Code / Codex 会话里的测试、设备随机数校验、真实 Claude Code / Codex 会话测试、Stream Deck / D200 按键屏原生插件、macOS 版、v2 硬件样机（现有实体屏是 1602 字符屏）。
- 使用说明：`pc/hub_README.md`（在资料包上一级的 `pc/` 目录里，单独打包 `agentdeck/` 时不随包）；开发说明：`research/brief-hub-v1*.md`。
