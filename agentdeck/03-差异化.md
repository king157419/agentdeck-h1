## 一、定位陈述（v2 修订）

**路演一句话定位：AgentDeck（暂名）是"跨所有 agent 的 Codex Micro + 高危操作的物理二次确认"。**

> 面向同时开着 3～10 个本地与云端 AI agent 的开发者，AgentDeck 是一块桌面物理调度台与硬件安全闸门：它在 Codex Micro 经典的"6 颗带灯矮轴会话键 + 批准/拒绝/按住说话大键 + 滚轮"形态上方，增加了一条 **3.2–3.5 寸 6 等分长条 IPS 状态屏**与**板载麦克风**（D1）。
> 日常低风险命令交给官方 Auto Mode 自动放行；设备专门解决 **"谁在等我（覆盖海外 CLI、国产 CLI 及云端异步 agent）→ 一键直达 → 按住说话派活 → 对不可逆高危操作（`git push`、生产环境 `ssh/kubectl`、数据库写入、改密钥、合并线上 PR）强制物理二次确认"**（D3）。
> 和锁死单一平台的 Codex Micro（$230，仅管 Codex、无屏无内置麦）[1][8][45] 与 claude-desktop-buddy（仅管 Claude Desktop）[9] 不同，它按跨厂商设计（Claude Code / Codex 已接入本地中枢，Cursor、Gemini 和国产 CLI 按各家钩子能力逐家列入路线图）；和罗技 MX Keypad（$99.99，薄膜键、无麦克风）[46] 与优篮子 AU05 Vibe Key（¥269，无屏幕）[2][47] 不同，它在 **¥499 / $99** 单款定价内同时补齐了分槽命令屏、真机械轴手感、板载对讲麦与硬件防呆锁（D2）。

**我们不卖什么：** 不卖"华强北无屏 AI 快捷键宏键盘"（已被 Keychron 压到 $34.99 [3]、被优篮子 AU05 压到 ¥269 [2]），也不卖"闭眼一键 YOLO 的盲批按钮"。

## 二、五个差异化点（v2 修订）

**总览：已砍掉原初稿中站不住的说法（如"深圳供应链成本碾压优篮子"、"优篮子锁死腾讯生态"、"靠自建分类器比 Claude 官方更准"、"向优篮子收 OEM 费"）。下面五点里没有任何一点靠硬件专利躺赢；真正的壁垒在于"中立协议持续适配 + 高危硬件确权 + 软件订阅生态"三件事组合推进，见《04-技术壁垒》。**

| # | 差异化（v2） | 证据强度 | 可复制性 / 被抄难度（诚实评估） |
|---|---|---|---|
| 1 | 全生态中立调度（海外 CLI + 国产 CLI + 云端异步 agent） | 强 | **中**：大厂因利益冲突不愿抄；第三方硬件厂与开源项目能抄"接入多家"，难点在双端持续维护与本地+云端统一槽位 |

### 1. 全生态中立调度：跨海外 CLI + 国产 CLI + 云端异步 agent（v2 修订）

**结论：重度开发者天然混用多家工具，且工作流正从纯本机终端向"本地 CLI + 云端异步 agent"并行延伸，而巨头硬件只管自家院子。**

证据：
- **用户在混用多家**：Stack Overflow 2026 调查里，Claude Code 使用率 66%、GitHub Copilot 59%，相加远超 100%，证明大量开发者同时用多家 [4]；JetBrains 数据显示 Codex 工作使用率半年内从 3% 涨到 16% [5]；国内大量开发者用"Claude Code 客户端 + 国产模型（GLM / Kimi / DeepSeek）"[33][34]，B 站单集教程播放达 15.7 万量级 [35]。
- **工具形态剧烈变动，且向云端迁移**：Google 2026-05 将 Gemini CLI 并入 Antigravity CLI [6]；Windsurf 2026-06 改名 Devin Desktop [7]；Cursor 年化收入冲上 $40 亿，核心驱动力之一是异步运行的 **Cloud Agents** 及支持本地/worktree/云端并行的 Cursor 3 [50]。绑死单一本地 CLI 的硬件极易过时。
- **巨头硬件锁死自家，国产接口已就绪**：Codex Micro 只服务 Codex [8]；claude-desktop-buddy 虽支持 Claude Desktop 内的 Claude Code 与 Cowork，但仍锁死 Anthropic 自家桌面端 [9]；国产 CodeBuddy（27 个钩子事件）、Qwen Code（23 个）、Kimi Code（20 个）均已开放事件接口 [10][11][12]。

**诚实说明（删去原错误论断）：** ① 优篮子 AU05 Vibe Key 并非绑死腾讯 WorkBuddy，其底层 Ulanzi Studio 同样支持 Claude Code、Codex、千问等通用映射 [47]；② VibeKeys 已支持 6 家海外 CLI 并接入状态钩子 [13][49]，开源项目 `puritysb/AgentDeck` 也在优篮子 D200 上支持多家 [14][48]。**因此"支持多家海外 CLI"已不是独家卖点，我们的差异在于把"海外 CLI + 国产 CLI + 云端异步槽位（Cursor Cloud Agent、Codex 云任务、GitHub PR/CI 阻塞，作为 P1）"统一进同一套 6 槽物理状态机（D3）。**

**可复制性：** OpenAI、Anthropic 因商业竞争**绝不会抄**。罗技、优篮子、VibeKeys 在技术上**可以抄**，但各家 CLI 钩子协议频繁破坏性变更，持续维护跨海内外 + 云端十余家工具的双平台（macOS/Windows）适配需要专职工程投入，属于"脏活累活堆出来的时间差壁垒"。

### 2. 会话级真控制：钩子防串窗直答，不是模拟按键宏（v2 修订）

**结论：并行开发最大的痛点是"不知道哪路会话卡住了"以及"切错焦点把回车或语音打进别的窗口"。**

证据：
- Claude Code 官方 issue #13024"需要知道什么时候该我输入"获 81+ 人反应 [15]；issue #36885 原话点破："瓶颈不再是 Claude 的速度，而是人发现 Claude 在等" [16]。
- Codex Micro 上排 6 颗"Agent 键"卖光 [8]，验证了"一槽一会话"的直觉交互；但它和 AU05 Vibe Key [47]、普通宏键盘一样，本质靠快捷键模拟交互，当前台焦点在编辑器或聊天软件时极易误触串窗。
- 底层直答路径明确：Claude Code 与 Codex 官方支持 `PermissionRequest` 钩子，守护进程直接返回 `allow/deny` 即可在后台完成确权，超时自动 fail-closed 退回终端原生提示 [17][18]。

**我们的做法：** 上方长条 IPS 屏按 6 等分精准对齐下方 6 颗矮轴会话键，实时显示对应会话的 agent 名、状态与待确认命令摘要；单击直达对应终端窗口/tmux 窗格（或拉起云端 agent 页面）；审批携带当前屏幕显示的随机数标识防切屏误批；按住板载麦克风说话严格路由至当前选中槽位。（注：跨 Windows/macOS 真钩子直答与国产 CLI 边界实测已列为路演前 6～8 周首要闭环项，见 D7。）

**可复制性：** 钩子文档完全公开，`agentsd`（仅 macOS）[22] 与 `vibekeys_app`（侧重状态同步）[49] 已用上同类机制，**原理门槛不高（低～中难度）**。难抄的是生产级稳定性：例如过滤 Claude Code `idle_prompt` 误报 [23]、绕过 Windows 高权限窗口输入隔离、多终端多窗格精确寻址等底层填坑积累（见《04》）。

### 3. 高危操作的物理二次确认：做开发者的硬件安全闸门（v2 修订）

**结论：官方默认 Auto Mode 正在消灭 80% 以上的普通弹窗——纯"一键批准键"即将贬值，只有"不可逆高危操作的物理二次确认（Hardware 2FA）"越往后越刚需。**

证据：
- **必须正视的官方数据**：Anthropic 于 2026-08-14 默认开启 Claude Code Auto Mode，官方披露用户原本就盲目批准了 **97%** 的权限提示；在 **1,053 名付费测试者**的安全对照实验中，人类手动审查只拦下了 **13.6%** 的危险动作，而官方 AI 分类器拦下了 **89%** [24][25][26]。
- **社区反感盲批，呼唤高危刹车**：Codex Micro 视频下高赞嘲讽"键盘上一个 yolo 按钮？尴尬到脚趾抓地" [27]；国内开发者歸藏实测物理键后反馈"`rm -rf`、`git push --force` 按物理按钮更慎重" [28]；Stack Overflow 调研中 60% 的使用者会阻止未经批准的系统改动 [29]。

**我们的做法（D3）：** 主动把 `ls`、`pytest` 等日常低风险命令交给官方 Auto Mode 自动放行；硬件重点拦截**跨边界、不可逆的高危动作**——包括 `git push`（尤其 `--force`）、生产环境 `ssh/kubectl`、数据库写入与迁移、修改密钥/环境变量、合并线上 PR。命中高危规则时，屏幕爆红显示命令摘要并锁死单次轻按，强制双击或长按二次确认；命中极危规则（如 `curl | sh`）直接禁止硬件放行。

**可复制性：** **交互功能本身极易被抄（低难度）**——任何带屏硬件改几行固件都能加"长按确认"。同时必须诚实承认：**在单一 Claude 场景下，我们的本地规则不可能比 Anthropic 官方 AI 分类器更准** [24]。我们真正的不可替代性在于：① **物理肌肉记忆层面的防呆摩擦**（软件弹窗会被习惯性点掉，实体双键/长按能强行打断惯性）；② **跨不同模型、CLI 与云端合入动作的统一硬件安全闸门**，并向上延伸为企业 Team 版的 MCP 工具白名单与审计留痕（D4）。

### 4. "长条屏 + 真机械轴 + 板载麦克风"混合结构：解开手感、成本与带宽三角（v2 修订）

**结论：去掉站不住的"6 块独立小屏"与"深圳成本碾压优篮子"，用 D1 混合结构在 ¥499 / $99 价位实现竞品全缺位的硬件体验组合。**

证据：
- **竞品全部偏科**：Stream Deck MK.2（$149.99）[19]、Logitech MX Keypad（$99.99）[20][46]、Ulanzi D200（$59.99 / ¥298+）[21] 用"整块底屏 + 透明导光键帽"，物理结构决定了**只能做硅胶薄膜按键，装不了中心不透光的标准机械轴，且三者均无内置麦克风**；反过来，Codex Micro（$230，无屏且无内置麦）[8][45] 与 Ulanzi AU05 Vibe Key（¥269，矮轴带麦但无屏幕）[2][32] 保住了机械键感，却彻底丢掉了分槽命令显示。
- **6 块独立小屏算不过账**：0.85 寸彩屏公开零售单价约 $4.90 起 [41]，6 块独立屏叠加排线组装不仅拉爆小批量 BOM，还会挤占 USB 刷屏带宽（见《07》）。

**我们的做法（D1）：** 定型为**"上方一条 3.2–3.5 寸长条高分 IPS 状态屏（画面精准 6 等分，紧贴下方 6 颗矮轴 RGB 会话键）+ 下方 ✓ / ✗ / 按住说话 3 颗大号机械键 + Ctrl/截图键 + 右侧金属滚轮 + 板载 MEMS 麦克风"**。一举同时保住：分槽看清命令摘要、全系真机械轴清脆盲操手感、按住即说的近场语音输入，以及可控的单屏 BOM。

**可复制性：** **诚实评估：高可复制（低壁垒）。** 这套结构属于工程巧思而非底层专利，更不能对国内同行吹嘘"深圳供应链优势"——优篮子母公司唯迹科技本来就在深圳 [32]。只要市场跑通，深圳成熟外设厂 **6 个月内就能开出同类模具**。硬件结构只是帮我们在前 18 个月打赢单品体验错位的敲门砖。

### 5. 免费软件兼容现成外设引流 + 单款硬件与双层订阅变现（v2 修订）

**结论：砍掉鸡肋 OEM 幻想与静态策略文件，用"零门槛免费软件获客 + 单品硬件现金流 + 强刚需个人/企业双订阅"跑通自造血闭环。**

证据：
- 纯软件编排器变现难、留存脆：Vibe Kanban（28.7k stars）宣布停更 [36]，Crystal 弃用 [37]，Stream Deck 插件仅卖 $1.99～3.99 [38]。
- 无软件蓄水的冷启动众筹必败：CtrlVibe 在 Kickstarter 主场仅获 59 人支持、筹约 1 万美元 [39][51]。
- 原 OEM 假设已被证伪：同名开源项目 `puritysb/AgentDeck` 已免费上架优篮子插件商店 [14][48]，优篮子不可能再为状态显示付每台 ¥5～15 授权费；原 Team 版若只发静态 JSON 策略文件也无法支撑国内投资人看重的持续订阅服务故事 [40]。

**我们的做法（D2 + D4）：**
1. **获客漏斗**：控制层软件永久免费，兼容用户手头已有的 Stream Deck、优篮子 D200、普通宏键盘（当前 Windows 端已支持 F13–F24 全局热键 + 置顶 6 槽小浮窗免驱使用，往 Stream Deck / D200 按键屏推状态的原生插件与 macOS 版列入路演前 8 周开发）——不靠低毛利 Lite 硬件引流，先把重度多开开发者圈进软件生态。
2. **硬件变现**：前 18 个月聚焦唯一主力单品（¥499 / $99），转化追求"板载麦 + 机械轴 + 6 等分屏 + 物理防呆锁"的核心用户。
3. **双层软件订阅（删去优篮子 OEM 预测）**：
   - **个人 Pro（¥19/月，$3.99/月）**：懂代码仓库上下文的专属语音纠错（精准识别项目内函数名、文件名与中英混杂术语）、离开工位时的手机只读状态看板、云端 agent 状态桥接；
   - **企业 Team（¥39–59/人/月）**：企业 SSO（飞书 / 企微 / 钉钉 / Okta）、支持私有化部署的安全合规仪表盘、MCP 工具白名单统一管控。

**可复制性：** "免费软件 + 硬件 + 订阅"的商业框架**谁都能模仿（低难度）**；但一旦用户把日常多开工作流、结合本地仓库索引的代码语音词库以及企业安全合规审计接入进来，迁移摩擦就会随时间累积（中高难度）。

## 三、定价阶梯（单款聚焦策略）（v2 修订）

**结论（对齐 D2/D4）：坚决砍掉原 Lite（¥299/$59），推迟原 Pro（¥999/$199），前 18 个月只做一款主力硬件——国内标价 ¥499（众筹早鸟 ¥399）、海外标价 $99（众筹早鸟 $79），正面卡在罗技 MX Keypad（$99.99）与 VibeKeys Max（$99）以内，不到标杆 Codex Micro（$230）的一半。**
