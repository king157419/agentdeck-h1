## 四、投资人最可能打断提问的 5 个位置及标准实战应答

### 打断点 1｜讲到第 4 页（或第 10 页）竞品对比时
- **为什么在这打断**：投资人一看到罗技 MX Keypad 9 块独立彩屏才卖 `$99.99` 且原生支持 Claude Code / Codex，优篮子 D200 应用商店里甚至已经有免费的同名开源插件 `puritysb/AgentDeck`，会立刻本能质疑你们是“大厂和存量外设上的一个免费插件功能（Feature），没必要买新硬件”。
- **投资人打断原话**：  
  *“等一下——罗技 9 颗屏幕键才卖 99 块 9 毛 9，优篮子 D200 上连跟你们同名的免费插件都上架了。程序员花 5 分钟装个免费插件就能看状态切窗口，凭什么花 499 块买你们一个没品牌的初创硬件？”*
- **标准实战应答（不硬杠硬件参数，用“交互物理刚需 + 借船出海”四两拨千斤）**：  
  > “您问到了最核心的点，这也是我们做完竞品深挖后立刻决定改名『点将台 / Baton』并砍掉 OEM 授权幻想的原因。开发者仍会买我们硬件有三个硬理由：  
  > 第一，**盲操手感与板载对讲麦**：罗技和 D200 是薄膜硅胶屏键、机身没麦克风；重度多开用户高频操作是‘一按说话派活 + 盲拍大键审批’，机械大键加板载麦的体感的确不是薄膜键能给的。  
  > 第二，**高危命令物理二次确认**：开源插件主要做状态显示和切窗，我们做到了 `PermissionRequest + PreToolUse` 双钩子三档风控加哈希链审计，把 `git push --force` 这类事故拦在物理双按上。  
  > 第三，更关键的是，**我们根本不把罗技和优篮子当死敌，而是当免费获客渠道**——我们的免费软件现在就能用热键加浮窗驱动它们，下一步补齐原生插件，先把这批最精准的多 Agent 用户圈进我们的软件池，未来赚他们 $3.99/月代码语音纠错和企业合规版的钱。”

### 打断点 2｜讲到第 6 页架构或第 8 页真实截图时
- **为什么在这打断**：懂 AI 工程的投资人脑子里马上会蹦出两个行业最新变化：① Anthropic 从 8 月起默认开启了 Auto Mode（AI 分类器拦下 89% 危险命令），普通弹窗大幅减少；② Cursor 冲上 $40 亿 ARR 靠的是 Cloud Agents，任务跑在云端容器里根本不调本机 `127.0.0.1` 钩子。同时技术型合伙人会当场核查截图是不是“真连了 Claude”。
- **投资人打断原话**：  
  *“停一下我确认两件事：第一，第 8 页这张图到底是连着真实 Claude Code 截的，还是你们自己写脚本喂的假数据？第二，现在 Claude 默认开 Auto Mode 不弹窗了，重度用户又在往 Cursor 云端 Agent 迁，半年后你这本地审批器是不是就没活干了？”*
- **标准实战应答（先 100% 坦白工程边界赢尊重，再用 Auto Mode 漏检与云端并行反证刚需）**：  
  > “先如实回答第一个问题：**这张图里本地中枢、转发进程、风险分级引擎和系统热键（F19/F20）全是真实进程在跑，但喂入的是模拟的真实格式事件，还没有接进登录后的 Claude Code 和信任钩子的 Codex 会话里**——因为本机账号登录和 `/hooks` 手动信任需要创始人交互完成，这正是我们下一步第 1 周的第一优先级任务，绝不拿演示模式充当真会话。  
  > 第二个问题恰恰是我们 v1.4 架构升级的原因：  
  > 1）Auto Mode 消灭的是 `ls`、`pytest` 这种日常噪音，这是好事，没人想一天按两百次同意；但对于 `git push --force`、删生产 `kubectl`、改数据库这类不可逆动作，AI 分类器依然会漏掉 11%，企业也不敢全自动放行。所以我们专门补上了不依赖弹窗的 **`PreToolUse` 高危强制闸门**，从‘高频审批器’升级成‘不可逆动作的物理 2FA 发射钥匙’，下一步就在真实 Auto Mode 会话里实测。  
  > 2）至于 Cursor 云端 Agent，它把单人并行上限从本机 3 个推高到了云+端 10 个，人更看不过来了。我们下一步会把这 6 个槽位通过 Webhook 和轮询升级成**‘本地 CLI + 云端异步 Agent / GitHub PR 阻塞统一任务槽’**，云端跑完待 Review 同样亮灯、一按直达 Diff 页面。”

### 打断点 3｜讲到第 9 页市场规模（3 年硬件 SOM 仅 ¥1,200–3,550 万）时
- **为什么在这打断**：主流 VC 合伙人对早期项目的底线预期是 5–7 年有机会冲向数亿人民币营收。看到你们自己算出“3 年全球+中国硬件 SOM 才 1.8–5.4 万台、一千多万到三千多万人民币”，会立刻贴上“小而美 Kickstarter 外设工作室（Lifestyle Business）”标签。
- **投资人打断原话**：  
  *“你们自己算的账很诚实，但全球加中国三年才卖两三万台、两三千万人民币的硬件盘子，就算你们做到 100% 满分，这也不是一个风险投资（VC）该投的体量啊？”*
- **标准实战应答（把“克制算小账”转化为认知优势，讲透“硬件保底不死 + 软件冲企业级上限”的不对称赔率）**：  
  > “如果今天我拿全球 4,800 万广义开发者乘以 $99 跟您吹一个 50 亿美金的硬件大饼，您肯定觉得我在忽悠。如果这只是一门纯卖键盘的生意，它确实只是个千万级流水的极客消费品，不值得拿 VC 的钱。  
  > 但在我们的商业设计里，**硬件承担的是‘零烧钱获客 + 现金流自造血底座’**：靠这 1.85 万台硬件毛利，我们不需要融 Pre-A 就能养活团队正向循环，先把物理入口钉在全球最愿意为效率付费的重度多 Agent 程序员桌面上。  
  > **真正给 VC 带来高赔率回报的，是上面那层脱离自家硬件也能独立扩张的软件与企业网关**——当一个研发团队每个人同时跑五六个 Claude、Codex 和国产 CLI 时，CTO 和安全负责人面临多厂商权限失控、MCP 工具乱调和 SOC2/等保审计黑洞。我们从个人桌面物理开关切入，往上长成按席位收费的**跨厂商企业 Agent 权限与合规审计平台**，这才是过亿体量的软件天花板。”

### 打断点 4｜讲到第 14 页财务模型（无书面报价 + 现金低点仅剩 ¥35.5 万）时
- **为什么在这打断**：投过硬件的合伙人都吃过开模延期、良率暴雷和关税涨价的亏。看到“零量产履历 + 尚无深圳工厂书面报价 + 2029 年 10 月账上最低只剩 ¥35.5 万”，会立刻质疑安全垫太薄、随便抖一下就断粮。
- **投资人打断原话**：  
  *“你们团队没做过硬件量产，现在连一家工厂的书面报价都还没拿到，模型里现金最低点竟然只剩 35.5 万！硬件随便开模返工一次或者元器件涨价 10%，这 35 万瞬间就穿仓了，你们怎么保证不死在半路？”*
- **标准实战应答（给出四道可写入投资协议的刚性风控锁）**：  
  > “您说得非常对，35.5 万的安全垫确实很薄，所以我们绝不靠拍胸脯赌运气，而是设计了四道硬锁：  
  > 第一，**交割前先验成本红线**：下一步 8 周内我们就会拿齐 2–3 家深圳代工厂的正式书面报价，1 万台档裸 BOM 死卡 **≤ ¥176**（含 15% 预留 ≤ ¥202）；拿不到这个成本，我们就减键、换小屏，或者国内早鸟严格限百台、主攻高毛利的 $99 海外市场（海外 10k 产品毛利率估算达 52%）。  
  > 第二，**产品极度克制**：前 18 个月砍死多 SKU，只做一款 USB-C 有线注塑版，不碰电池、无线认证和复杂透光定制轴。  
  > 第三，**1,500 订金开模扳机**：2027 年 7 月如果全球 $1/¥9.9 付费订金不到 1,500 人，绝对不开硬模、不启动众筹，直接留着账上约 **¥150–160 万**转做纯软件，最多只亏 6.4 万投流测试费。  
  > 第四，**首位全职补强 + 现金砍线**：首期款到账第一天就招有深圳 10k 量产经验的结构/供应链老兵把关 DVT；同时设定 2028 年 6 月和 2029 年 6 月两道现金警戒线，低于 ¥80 万立即冻结扩编、砍半投放。”

### 打断点 5｜讲到第 15 页融资诉求（0 外部用户却要 ¥2,500 万投后估值）时
- **为什么在这打断**：国内早期市场当前非常挑剔，面对“外部用户为 0、3.5 寸彩屏手板未出、真会话未联调”的早期团队，投资人天然会尝试把投后估值压回 ¥1,200–1,500 万的纯种子水位。
- **投资人打断原话**：  
  *“我很喜欢你们的诚实和底层工程能力，但说实话，今天你们外部用户是 0、彩屏真机还没点亮、工厂报价也没有，张口要 2,500 万投后估值太贵了。我按 1,500 万投后给你们出 250 万一次到账，你们接不接？”*
- **标准实战应答（算清现金流死局拒绝低额单笔 + 用“8 周前置交付 + 两期对赌”换取估值尊重）**：  
  > “非常感谢您的认可！跟您交个实底：我们在财务模型里专门跑过‘一次拿 250–300 万’的方案——如果按完整软硬节奏走，**300 万在 2028 年 8 月现金就会转负到 -165 万**，逼着我们在硬件毛利率只有 16%、软件收入刚起步的最难看时刻去求 Pre-A，那对我们和老股东都是死局。  
  > 同时，我们也绝不要求您在今天‘零用户、零报价’的状态下盲签 2,500 万估值。我们的建议非常清晰：  
  > 第一，**先看我们接下来 6–8 周的五项硬交付**：双平台真会话 5 天零错批、30–50 名多开重度开发者跑出 ≥40% 的两周留存、深圳工厂 ≤¥176 书面报价、微雪 3.49 寸真机手板，以及 300+ 真实付费订金。我们用实打实的数据来支撑 2,500 万估值。  
  > 第二，**分两期交割把您的风险砍半**：首期您只出 ¥250 万陪我们跑软件公测和工程验证；真正的第二笔 ¥250 万量产弹药，只有在我们做到了**‘2,000 软件周活 + 1,500 付费订金或 50 万众筹’**之后才打款。您用种子轮的单笔试错成本，锁定了一家能一轮钱自己跑到盈亏平衡的完整公司。”
