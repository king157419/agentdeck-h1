## 一、总体判断：会不会投、为什么

### 结论：**当前状态下不投（Pass / 暂不上投决会），但列入“高优先级跟踪（Track）”；若团队在 6～8 周内补齐两个前置验证并调整交易结构，愿意给出一张 ¥250～350 万的种子轮 TS。**

把话说透：在过去两年看过上百个满嘴“端侧大模型、颠覆手机、百亿美金 TAM、硬件专利壁垒”的 AI 硬件项目之后，**你们的材料是我今年读过最诚实、工程颗粒度最细、最不把投资人当傻子的一份**。但我今天如果把这份案子推上基金投决会（IC），要“投后 ¥3,000 万、出让 20% 融 ¥600 万”，一定会被合伙人们一票否决。原因不在“需求是不是真的”，而在下面四笔冷酷的账：

1. **这是一个典型的“真痛点，但极易沦为大厂/装机量硬件上的一个插件（Feature，而非独立硬件公司）”，且天花板对主流 VC 偏窄。**  
   你们在《01》和《08》里非常诚实地算出了底牌：3 年全球+国内可得市场（SOM）仅 **1.7 万～5.1 万台（¥1,300 万～3,900 万）**；基准财务模型下，到 **2029 年（第 3 年）才卖 1.34 万台、总营收 ¥856 万（其中软件仅 ¥55 万，占 6.4%），当年仍净亏损 ¥319 万，三年累计烧钱近 ¥1,000 万**。做个残酷的对比：这更像一门年流水千万级的精品极客外设/Kickstarter 生意（Lifestyle Business），而不是能在 5～7 年冲到 ¥3～5 亿营收的典型风险投资标的——除非你们的软件层（跨端调度 + 企业 Agent 权限网关）能真正脱离自家硬件独立放量。

2. **关键竞品盲区直接击穿了你们的海外定价与 OEM 故事。**  
   你们把 **Logitech MX Keypad** 的价格标为【待核实】，但我核查后发现：**罗技这块 9 键全彩独立 LCD 屏、原生支持 Copilot / Claude Code / Codex、带官方 SDK 的开发者控制台，官方零售价只有 $99.99！** 你们作为零品牌认知的初创学生团队，6 键注塑壳有线版 Standard 居然在海外定 **$129**？国内同样残酷：优篮子不仅有 ¥269 的铝壳无线带麦 Vibe Key（且**并未锁死腾讯生态**），它的 D200（13 键 LCD 屏，国内淘宝约 ¥500～598，海外 $59.99）应用商店里，**已经免费上架了与你们同名的开源项目 `puritysb/AgentDeck`**。

3. **产品技术方案（06/07）与财务模型（08）之间存在致命的“精神分裂”。**  
   《06-PRD》与《07-技术方案》全篇按 **“6 块独立 0.85 寸 SPI 小屏 + 机械轴 + 售价 ¥599”** 设计；而《08-商业模式》算完账发现这套方案 1k 台毛利率 **-23%**、10k 台国内毛利率仅 **14%**，于是财务作者单方面改成了 **“Stream Deck 式一整块底屏 + 透明导光键帽 + 售价 ¥699”**——却没意识到整块底屏方案在结构上只能做硅胶薄膜按键，根本装不了不透光的标准机械轴！这意味着你们连最核心的 **物理结构、BOM 成本与定价三角** 都还没闭合。

4. **财务模型里的“2028Q3 断头台”在当前一级市场融不到 Pre-A。**  
   按 `08-财务模型.csv`，¥600 万融进来，烧到 2028Q2 末只剩 ¥125.6 万，2028Q3 现金直接变负（`-¥14.2 万`），必须靠一笔 ¥1,500～2,000 万的 Pre-A 续命。但看看 2028Q2 你们交出的成绩单：单季硬件收入仅 ¥47.9 万、单季毛利 ¥7.4 万（毛利率 15.5%）、软件订阅收入 **¥0**！在今天挑剔的中国一级市场，没有任何 Pre-A 机构会给这个财务面貌的硬件公司开出两千万支票。

**为什么我仍然高度关注、甚至愿意在调整后给种子轮 TS？**  
因为多 Agent 并行时代的“人机注意力调度与高危操作物理确权”是一个刚刚裂变出来的真命题，而你们团队展现出的底层排障能力（WinUSB、UIPI、Hook 状态机）和极度克制的求真态度，在同龄创业者里万里挑一。只要把“重资产多 SKU 硬件幻想”砍掉、把价格和结构对齐、先把免费软件的真实留存跑出来，这依然可以是一个极佳的“小步快跑、进可攻企业级 Agent 管控、退可做高利润出海 DTC 极客硬件”的好案子。

## 三、最致命的 5 个问题和对应修改建议

### 致命问题 1：工程方案（06/07）与财务模型（08）严重打架——“机械轴 + 屏幕 + 毛利率”的不可能三角根本没闭合
* **问题剖析**：
  * 《06-PRD》和《07-技术方案》写的是 **6 块独立 0.85" IPS 屏 + 机械轴 + 标价 ¥599**（1k 台整机 BOM 约 ¥500～570）；《08-商业模式》算完发现这套 BOM 在 1k 台毛利率 **-23%**、10k 台国内仅 **14%**，于是直接改成 **“一块整屏 + 导光 + 透明键帽（BOM ¥60/¥40）+ 标价 ¥699”**，但 BOM 表里居然还保留着 ¥57/¥36 的机械轴成本！
  * **硬件常识警告**：Stream Deck 和优篮子 D200 能用“整块大屏 + 透明键帽”，是因为它们用的是**薄膜硅胶碗结构**，屏幕上方没有遮挡物；而**标准机械轴中心是不透光的轴体与金属弹片**，底下铺一整块 LCD 屏根本看不见图案！如果硬做全透光定制机械轴或键帽嵌屏排线，开模良率地狱足以烧光你们全部融资。连 `devlog.md` 都坦白概念爆炸图里画成了“6 块屏配 5 颗轴”，如果被懂硬件的投资人现场抓包，信任度直接归零。
* **修改建议**：
  1. **本周内拉齐 ID 结构与 BOM，推荐采用“混合架构”破局**：
     * **方案 A（最稳妥、手感与成本兼得）**：上方一条 **3.2～3.5 寸长条高分 IPS 状态屏（画面精准 6 等分，紧贴下方 6 颗真热插拔矮轴会话键）** + 会话键 RGB 状态灯 + 下方 **真机械大键（✓ / ✗ / 说话）**。BOM 比 6 块独立屏立省 ¥150+，全系保留机械轴清脆手感，且彻底避开 USB 全速 HID 刷 6 块独立屏的带宽瓶颈。
     * **方案 B（坚持键上屏）**：上方 6 个会话键老老实实用成熟的 **整块 LCD + 定制高段落感硅胶导光键帽**（向优篮子 D200 供应链看齐），**只在下方 ✓ / ✗ / 说话键用真机械轴**——把好钢花在最高频盲操的 3 个大键上。
  2. 全套文档立刻统一售价与 BOM 口径，严禁 PRD 写 ¥599、财务表算 ¥699。

### 致命问题 2：海外 $129 / 国内 ¥699 定价被罗技与优篮子上下夹击，且初期铺 3 个硬件 SKU 纯属自杀
* **问题剖析**：
  * 海外市场：罗技 **MX Keypad 9 键 LCD 屏只卖 $99.99**，VibeKeys Max（带屏+内置麦+无线）只卖 **$99**，Stream Deck Neo 也是 **$99.99**。初创品牌 6 键注塑有线版卖 **$129** 毫无价格竞争力。

### 致命问题 3：“官方默认 Auto Mode 消灭审批”与“企业 Agent 往云端后台迁移”正在掏空纯本地 CLI 硬件的场景
* **问题剖析**：
  * Anthropic 的实测数据其实在给所有“手动审批器”敲丧钟：人类手动审查只拦住了 **13.6%** 的危险操作，官方 AI 分类器拦住了 **89%**。未来一年，各家都会普及默认 AI 分类器，常规本地命令弹窗会锐减 80% 以上。
  * 更要命的是 Cursor 冲上 $4B ARR 的信号：越来越多重度多 Agent 用户开的是 **Cursor Cloud Agents、Codex Web、GitHub Copilot Coding Agent、Devin** —— 这些 Agent 跑在云端容器里，根本不在本机产生 `pid_chain`，也不弹窗调本地 `127.0.0.1` 的 command hook！如果你们只盯着本机终端窗口切换，重度用户越往后升级工作流，你们能管住的会话比例反而越低。
* **修改建议**：
